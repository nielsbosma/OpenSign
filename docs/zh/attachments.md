# 签署人附件

你可以要求参与方在签署时上传文件：身份证件副本、证书、银行对账单。这些文件会经过清理、加密存储，并与其余证据一起封存进已签署的 PDF。

## 请求附件

在参与方对话框的**请求附件**下，为每个你需要的文件添加一行：

| 字段 | |
| --- | --- |
| 姓名 | 你要求的内容，例如“身份证件副本”。会显示给参与方。 |
| 说明 | 可选。向参与方提供更多细节。 |
| 必填 | 必填的附件必须上传后，参与方才能签署。可选的可以跳过。 |

你可以向每位参与方请求最多 10 个附件。从[模板](templates.md)创建文档时，附件请求会被复制，也可以通过 API 使用参与方的 `attachments` 列表来设置。

## 签署人看到什么

签署页面在**附件**下列出所请求的文件，每个文件都有**上传**、**替换**和**删除**。参与方在签署之前可以更改自己的上传。

- 接受的类型：PDF、JPEG 和 PNG，每个最大 10 MB。
- 文件按内容而不是文件名检查。

## 文件如何清理

- **PDF** 与其他任何上传一样被重写：没有 JavaScript、表单动作、嵌入文件或 XFA，最多 50 页。
- **图片**会被解码后重新编码为 PNG。这会丢弃所有元数据，例如手机照片中的 GPS 位置，以及文件中隐藏的任何内容。非常大的图片（超过 40 百万像素）会被拒绝。
- 其他任何内容都会被拒绝。

## 在封印后的 PDF 中

文档封印时，每个附件会：

- 列在证据页上，包含参与方、你所要求的名称、文件名及其 SHA-256 哈希，并且
- 作为文件附件嵌入封印后的 PDF，因此它随文档一起传递，并受印章保护。

在 PDF 阅读器中打开封印后 PDF 的附件面板即可查看。参见 [封印 PDF 与证据](sealed-pdfs.md)。
