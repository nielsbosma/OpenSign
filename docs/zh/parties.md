# 参与方、角色与签署顺序

参与方是参与文档的任何人：签署的人、审批的人，或只接收已签署副本的人。你在文档页面的**参与方**下添加参与方。

## 参与方详情

| 字段 | |
| --- | --- |
| 姓名 | 必填。显示在签署页面和证据中。 |
| 角色 | 签署、审批或接收副本。见下文。 |
| 邮箱 | 邮件投递和接收已签署副本所需。 |
| 手机 | 带国家代码，例如 `+46 70 123 45 67`。短信投递和短信验证码所需。 |
| 公司 | 可选。用于填入公司字段。 |
| 语言 | 其邮件、短信和签署页面的语言。默认为**与文档相同**。参见 [签署页面](signing-page.md#languages)。 |
| 链接发送方式 | 参与方如何拿到其签署链接。参见 [投递](#delivery)。 |
| 查看前验证身份 | 参与方在能打开文档之前必须做什么。参见 [身份验证](identification.md)。 |
| 签署前验证身份 | 参与方在能签署之前必须做什么。参见 [身份验证](identification.md)。 |
| 要求网络摄像头身份验证 | 参与方在签署前为自己拍一张照片。参见 [网络摄像头照片](identification.md#webcam-photo)。 |
| 个人身份号码 | 用于电子身份验证。设置后，只有此人的电子身份才能签署。加密存储并以掩码显示。 |
| 签署顺序 | 当文档按顺序签署时，数字小的先签。参见 [签署顺序](#signing-order)。 |
| 请求附件 | 参与方必须或可以上传的文件。参见 [签署人附件](attachments.md)。 |

## 角色

| 角色 | 参与方做什么 |
| --- | --- |
| **签署**（签署人） | 阅读文档，填写自己的字段，并用手写或输入的签名签署。 |
| **审批**（审批人） | 阅读文档并批准。没有签名图像，但批准会像签名一样记录在证据中。 |
| **接收副本**（查看者） | 不需要操作。文档完成时收到封印后的 PDF。查看者不能有字段。 |

当每位签署人和审批人都已操作时，文档即告完成。

## 投递

| 选项 | |
| --- | --- |
| **邮箱** | 默认选项。OpenSign 会发送带有个人链接的邀请邮件，如果开启了提醒，还会发送提醒。 |
| **短信** | OpenSign 通过短信发送链接。需要在**设置 → 短信**中配置短信提供商。 |
| **链接（由你交付）** | OpenSign 不发送任何内容。你发送文档时，它会显示供你转交的链接，例如放入你自己的邮件或聊天，或通过[嵌入式签署](embedding.md)在你自己的应用中显示。 |
| **当面（在你的设备上）** | 参与方在你的电脑或平板上签署，从文档页面开始。参见 [当面签署](in-person.md)。 |
| **无** | OpenSign 不发送任何内容，也不显示链接。适用于只需要已签署副本的查看者，副本会发到其邮箱地址。 |

在此实例上尚未设置好的选项会显示出来，但在管理员设置好之前无法选择。

### 签署链接

每位参与方都有一个个人链接。它只对该参与方有效，并在以下情况失效：

- 文档完成、被拒绝、被取消或过期，
- 链接自身的有效期结束：文档的过期日期，否则为**设置 → 安全**中设置的天数（默认 30），从首次通知该参与方时算起，或者
- 为该参与方签发了新链接，这会撤销旧链接。

链接的秘密部分位于 `#` 之后，因此永远不会进入服务器日志，签署页面还会把它从地址栏中移除。参见 [安全模型](security.md#signing-links)。

## 签署顺序

默认情况下，所有人同时被邀请，可按任意顺序签署。在**参与方**卡片上开启**按顺序签署**，即可一步一步地邀请参与方：

- 每位签署人和审批人都会显示其步骤编号。开启顺序后，从参与方当前列出的顺序开始。
- 使用参与方卡片上的箭头把参与方提前或移后。
- 要让多位参与方在同一步中一起签署，请在**编辑**下给他们相同的**签署顺序**编号。数字小的先进行。
- 当一个步骤中的所有人都已操作，OpenSign 会邀请下一步。
- 在轮到自己之前打开链接的参与方会看到“其他人需先签署”，轮到时会收到邮件。

查看者不属于顺序的一部分。他们在最后收到封印后的 PDF。

## 拒绝

签署人或审批人可以拒绝，并可附上原因。拒绝会使文档对所有人停止：它变为**已拒绝**，所有链接失效，发送人会被告知，并且会触发带有该原因的 `document.declined` Webhook。

## 更改参与方

文档处于草稿时可以更改参与方。删除参与方也会删除其字段。文档一旦发送，参与方就固定了；要更改，请取消该文档并新建一份。
