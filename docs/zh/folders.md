# 文件夹与归档

文件夹用于给文档和模板分组，归档则让已完成的工作不碍事。两者只改变事物在列表中的位置，从不改变谁能看到某份文档、它如何保存，或它会发生什么。

## 文件夹

**文档**和**模板**页面的左侧有一列文件夹。**所有文档**（或**所有模板**）列出所有内容，无论其在哪个文件夹中；选择某个文件夹则列出直接位于其中的内容。在窄屏幕上，文件夹是列表上方的一个菜单。

- 文档和模板各有独立的文件夹。文档不能放进模板文件夹，反之亦然。
- 文件夹最多嵌套三层，例如 *客户 / Acme / 2026*。
- 同一文件夹内的名称是唯一的，不区分大小写。
- 一份文档或模板最多位于一个文件夹中，也可以不在任何文件夹中。

### 将内容移入文件夹

- 把一行拖到文件夹列中的某个文件夹上。拖动已选中的一行会移动所有选中的行。拖放到**所有文档**上会把它们移出其文件夹。
- 或者勾选若干行，打开**操作**并选择**移动到文件夹**。
- 在文档或模板页面上，**移动到文件夹**位于**更多**菜单中。
- 在打开某个文件夹时用**新建文档**创建的文档会放入该文件夹。

移动在任何状态下都可进行，并以 `document.moved` 记录在审计日志中。

### 谁可以做什么

| | 文档文件夹 | 模板文件夹 |
| --- | --- | --- |
| 查看文件夹 | 所有人 | 所有人 |
| 创建文件夹 | 任何能发送文档的人（`documents.create`） | `templates.manage` |
| 重命名、移动或删除文件夹 | 创建者，以及拥有 `documents.manage_all` 的人 | `templates.manage` |
| 将项目移入文件夹 | 任何可以修改该项目的人 | 任何可以修改该模板的人 |

文件夹对整个组织共享，但**文件夹从不授予访问权限**。人们只能看到他们原本就能看到的文档：自己的、与他们共享的，或者在其角色允许时的全部文档。两个人打开同一个文件夹，看到的文档可能不同，文件夹旁边的数字也只统计你能看到的内容。参见 [用户与角色](users-and-roles.md)。

### 删除文件夹

删除文件夹不会删除其中的任何内容。它的文档、模板和子文件夹会上移到它原来所在的文件夹，或移到顶层。如果那里已经有同名的子文件夹，被删除文件夹的名称会以括号附加到其后。

## 归档

归档已完成的文档和你不再使用的模板，让常规列表保持简短。

- 文档在**已完成**、**已拒绝**、**已取消**或**已过期**之后才能归档。草稿和等待中的文档不能归档。
- 模板可以随时归档，除非有基于它的批量发送仍在运行。已归档的模板不会出现在**新建文档**中，在恢复之前也不能用于新文档或[批量发送](bulk-send.md)。
- 状态标签页旁边的**已归档**标签页会列出归档内容，搜索和文件夹在其中同样可用。已归档的文档保留其所在文件夹。
- 勾选若干行并选择**操作 → 归档**即可一次归档多个，或在文档页面的**更多**菜单中使用**归档**。**恢复**可将它们带回。

归档所需的权限与修改该文档或模板相同。它以 `document.archived` 和 `document.unarchived` 记录在审计日志中。

### 归档与保留

归档不是回收站，也不是单独的存储。[保留规则](retention.md)按与其他文档相同的时间表删除已归档的文档，处于法律保全的文档仍保持保全。已归档的文档仍可下载和验证。

## 通过 API

| 方法 | 路径 | |
| --- | --- | --- |
| GET | `/folders?scope=documents` | 列出文件夹：`documents` 或 `templates`，含 `parentId` 和 `itemCount` |
| POST | `/folders` | 创建文件夹。请求体：`scope`、`name`，可选 `parentId` |
| PUT | `/folders/{id}` | 重命名或移动。请求体：`name` 和 `parentId`（`null` 表示顶层） |
| DELETE | `/folders/{id}` | 删除；其内容上移一级 |
| POST | `/documents/move` | 请求体：`ids`（最多 200 个）和 `folderId`（`null` 表示不在任何文件夹） |
| POST | `/documents/archive` | 请求体：`ids`（最多 200 个）和 `archived`（`true` 表示归档，`false` 表示恢复） |

`GET /documents` 和 `GET /templates` 接受 `folderId`（仅直接位于该文件夹中的内容）和 `archived=true`（返回归档而非常规列表）。`POST /documents` 接受 `folderId`。`documents.counts` 会在各状态计数旁返回一个 `archived` 计数。参见 [REST API](api.md)。
