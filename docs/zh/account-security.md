# 登录、通行密钥与双重验证

你的账户由密码保护，最好再加上第二重验证：身份验证器应用或通行密钥。这两项都在**设置 → 账户**下管理。

## 密码

- 至少 12 个字符。欢迎使用长口令。
- 密码使用 Argon2id 做哈希。包括管理员在内，任何人都无法读取它们。
- 同一地址多次登录失败后，该地址会被暂时锁定对此账户的登录，从一分钟开始，逐步增加到一小时。一天内没有失败则会清除记录。只有来自多个地址的同时失败才会让账户对所有人锁定，即便如此，通行密钥仍可登录。每次尝试都会被记录。
- **修改密码**会要求输入当前密码，并让你的其他会话退出登录。
- 登录页面上的**忘记密码？**会通过邮件发送一小时内有效的重置链接。重置会让每个会话退出登录并撤销你的 API 密钥，如果有任何密钥被撤销，你会收到一封邮件。如果你的账户有通行密钥，之后登录仍然需要它。

## 使用身份验证器应用的双重验证

1. 在**双重验证**下开始设置，并用身份验证器应用扫描二维码，例如 1Password、Google Authenticator 或 Microsoft Authenticator。
2. 输入 6 位验证码进行确认。
3. 保存**恢复码**。如果你丢了手机，每个恢复码可让你登录一次。它们只显示这一次。

此后，登录时在输入密码之后会要求输入验证码。如果你同时丢失了手机和恢复码，管理员可以重置你的双重验证（参见 [用户与角色](users-and-roles.md)）。

## 通行密钥

通行密钥让你可以用 Face ID、Touch ID、Windows Hello、手机或安全密钥登录，无需输入密码。

1. 在**通行密钥**下，选择**添加通行密钥**，为它起个名字（例如“MacBook”）并确认你的密码。
2. 按浏览器的提示操作。

然后在登录页面选择**使用通行密钥登录**。通行密钥始终会在设备上验证你（通过指纹、面部或 PIN），所以它本身就相当于双重验证，不会再要求验证码。你可以添加多个，也可以移除其中任何一个。

一旦你的账户有了通行密钥而没有身份验证器应用，仅凭密码就不能再登录：输入密码之后还会要求通行密钥。如果你丢失了所有通行密钥，管理员可以重置你的双重验证，这会将它们移除。

## 确认是你本人

创建 API 密钥或连接应用会带来持久的访问权限，所以 OpenSign 会先要求你输入密码或使用通行密钥，除非你在最近十分钟内登录或确认过。

## 要求所有人启用双重验证

管理员可以在**设置 → 安全**中开启**要求所有人启用双重验证**。此后，没有身份验证器应用或通行密钥的人，在做任何其他事情之前都会被要求先设置一个。以此类账户登录的 MCP 客户端在设置完成之前会被拒绝。我们建议开启它。

## 单点登录

如果你的组织使用[单点登录](single-sign-on.md)，请在登录页面选择它的按钮。随后由你的身份提供方处理你的密码、第二重验证和邮箱，**设置 → 账户**中就不会有通行密钥、身份验证器应用或密码。这类账户不能使用 API 密钥和 MCP 客户端。

## 语言

在**设置 → 账户与安全**下，选择 OpenSign 对你显示所用的语言：英语、简体中文、印地语、西班牙语、法语、阿拉伯语、孟加拉语、葡萄牙语、俄语、乌尔都语或瑞典语。登录之前，应用会跟随你的浏览器，登录页面上有语言选择器。这不会改变签署人看到的内容；他们得到的是文档或参与方上设置的语言。服务器的一些消息仍是英语。

## 已保存的签名

在**设置 → 账户与安全 → 我的签名**下，手写或输入一次你的签名，也可以添加你的姓名缩写。当你自己签署文档时，签署页面会在**已保存**标签页上提供它。它不会自动应用：你仍需选择签署，也可以改为手写或输入一个新的。

只有在签署链接属于你时才会提供它：当你[自己签署文档](in-person.md#signing-a-document-yourself)，或在登录状态下打开发到你自己邮箱地址的链接时。你为当面签署而把设备交给的人永远看不到它。该手写图像与其他所有文件一样加密存储，**移除**会将其删除。保存和移除都会记录在审计日志中。

外部签署人没有账户，所以他们可以改为勾选**在此浏览器中记住我的签名**。这只会把签名保存在他们的浏览器中，下次提供给同名的参与方；在不同文档之间，服务器上不会存储关于他们的任何信息。参见 [签署页面](signing-page.md#signing)。

## 会话

会话是脚本无法读取的浏览器 cookie，绑定到你的实例，并在服务器上仅以带密钥的哈希存储。管理员在**设置 → 安全**中设定：

| 设置 | 默认值 | |
| --- | --- | --- |
| 会话时长（小时） | 12 | 一次登录最长持续多久。 |
| 闲置多久后退出登录（分钟） | 60 | 会话在无人使用的情况下能保留多久。 |

用户菜单中的**退出登录**会结束此浏览器中的会话。

## 通过 MCP 连接的应用

在 **AI 应用（MCP）**下，你可以看到你的实例的 MCP 服务器地址，以及你已连接的客户端，例如 Claude。你可以随时断开其中任何一个。参见 [MCP 与 Claude](mcp.md)。

## API 密钥

API 密钥在**设置 → API 密钥**下管理。参见 [REST API](api.md#api-keys)。
