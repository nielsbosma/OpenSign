# 批量发送

批量发送会把[模板](templates.md)发送给电子表格的每一行。每一行都成为一份独立的文档，有自己的参与方和字段值，各自发送和跟踪：给每位租户一份新租约，给每位员工一份政策更新。

## 开始之前

- 准备一个模板，包含你想要的参与方、字段、留言和身份验证。
- 准备一个 CSV 或 Excel（`.xlsx`）文件。较旧的 `.xls` 和 OpenDocument `.ods` 文件请先另存为 `.xlsx`。第一行是列名。最多 1,000 行和 5 MB。
- 你需要有发送文档的权限。

## 发送

1. 打开模板，在其菜单中选择**批量发送**。
2. 选择文件。OpenSign 会读取它，并显示每一列、它的第一个值，以及它**填入**什么。
3. 检查映射。可以更改任何一列的目标，或选择**忽略**。
4. 也可以设置**文档标题**，这是一个把列名放在大括号中的模式，例如 `Lease {Address}`。留空则使用模板的标题和第一位参与方的姓名。
5. 修正 OpenSign 在**发送前请修正这些行**下列出的所有行。
6. 发送。OpenSign 会在后台创建并发送文档，并打开该批量发送的进度页面。

## 一列可以填入什么

| 目标 | |
| --- | --- |
| 某位参与方的姓名、邮箱、手机、公司或个人身份号码 | 模板中的每位参与方各有一组。 |
| 字段 | 模板中任何带标签的字段，作为该行发送人的值填入。数字两种写法都可以（`1 234,50` 或 `1,234.50`），日期可写为 YYYY-MM-DD 或该字段的格式，列表字段按选项文本填写，多个选项以逗号分隔。违反字段检查的值会使该行失败。 |
| 标题 | 文档标题，代替模式。 |
| 你的编号 | 文档的外部 ID，例如客户编号。 |
| 某位参与方的语言 | 该签署人的邮件和签署页面所用的语言，以 `sv` 或 `pt-BR` 这样的代码表示。参见 [签署页面](signing-page.md#languages)。 |

## 列的匹配

OpenSign 按名称匹配列，支持英语和瑞典语。例如“Email”“E-post”和“Mail”都匹配参与方的邮箱，“Mobile”“Mobil”和“Telefon”匹配手机号码。当模板有多位参与方时，以参与方名称开头的列，例如“Guarantor email”，会归该参与方。

如果管理员已设置 AI，你可以让 AI 匹配内置规则无法匹配的列。发送给它的是列名。它还会得到几行示例，但前提是管理员允许将文档文本发送给 AI 提供商。参见 [AI 助手与审阅](ai.md)。

## 行检查

在发送任何内容之前，每一行都会被检查：每位参与方都需要姓名；如果通过邮件接收链接，需要有效的邮箱地址；如果通过短信接收，需要有效的手机号码；等等。只要有任何一行会失败，就不会发送任何内容，OpenSign 会按电子表格的行号列出问题。修正文件后重新选择它。

## 进度

批量发送页面显示每一行及其收件人、状态，以及指向其所创建文档的链接。**模板**页面底部的**批量发送**会列出最近的运行。

**停止**会跳过尚未发送的行。已经发出的文档仍在等待签署；如有需要，请逐个取消。

**导出数据**会下载每位收件人填写的内容，每份文档一行，格式为 Excel、CSV 或 JSON。参见 [导出已填写的数据](data-export.md)。

## 隐私

批量发送运行期间，行数据会被加密存储，并在每一行的文档发出后从该行中删除。

## 通过 API

批量发送可通过 `POST /api/v1/bulk-sends/preview`（读取文件并给出建议的映射，不发送任何内容）和 `POST /api/v1/bulk-sends`（发送）使用。参见 [REST API](api.md#bulk-send)。
