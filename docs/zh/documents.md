# 文档

OpenSign 中的一份文档由一个或多个待签署的文件、参与其中的参与方，以及每个参与方要填写的字段组成。你先把它准备成草稿，然后发送，之后 OpenSign 会接手，直到它被签署、拒绝、取消或过期。

## 文档的生命周期

| 状态 | 含义 |
| --- | --- |
| **草稿** | 你还在准备中。文件、参与方和字段都可以更改。 |
| **等待中** | 已发送，正在等待签署。它的文件已被锁定为一份不能再更改的 PDF。 |
| **已签署** | 所有需要操作的人都已签署或批准。封印后的 PDF 已就绪。 |
| **已拒绝** | 有参与方拒绝了。对所有人而言签署都已停止。 |
| **已取消** | 发送人（或经理）终止了它。 |
| **已过期** | 在所有人签署之前，截止日期已过。 |

已发送的文档无法编辑。要更改一份等待中的文档，请先取消它，再新建草稿。

## 创建文档

在**文档**页面选择**新建文档**。拖入一个或多个文件，或者从[模板](templates.md)开始，并为文档填写标题。

### 文件

- **PDF** 文件会原样接收，但要先经过清理（见下文）。
- **Word**（`.docx`、`.doc`）、**OpenDocument**（`.odt`）和 **RTF** 文件由 Gotenberg 转换为 PDF。这需要实例上有转换器；没有转换器时只接受 PDF。
- 一份文档可以有多个文件。发送时，它们会按顺序合并为一份 PDF。
- 最大上传大小由管理员在**设置 → 安全**中设定（默认 25 MB）。

文件中的文本标签和可填写的表单字段会在上传时变成字段。OpenSign 会告诉你添加了多少个，以及哪些标签无法使用。参见 [文本标签、表单导入与字段检测](text-tags.md)。

每份 PDF 都按内容而不是文件名检查，并被重写，去除其中的 JavaScript、表单动作、嵌入文件、XFA，以及启动和 URI 动作。如果有内容被移除，OpenSign 会告诉你移除了什么。包括签署人在内，任何人都不会看到原始的活动内容。

### 详情

| 设置 | |
| --- | --- |
| 标题 | 显示在文档列表、邀请邮件和签署页面上。 |
| 给参与方的留言 | 显示在邀请邮件和签署页面上。 |
| 签署人语言 | 邮件、短信和签署页面使用的语言，除非参与方有自己的语言。留空则使用**设置 → 组织**中的默认值。参见 [签署页面](signing-page.md#languages)。 |
| 过期时间 | 超过该日期后文档不能再被签署，随后变为**已过期**。 |
| 每隔多少天提醒 | 每隔若干天（最多 60 天）向尚未签署的参与方发送一次提醒。0 表示关闭提醒。 |
| 你的编号 | 外部 ID，例如 CRM 或案件编号。你可以在文档列表中搜索它，它也会包含在 Webhook 和 API 中。 |

### 参与方

添加所有要签署、批准或接收副本的人。为每位参与方选择其角色、链接如何送达他们，以及他们必须如何验证身份。同一张卡片上的**按顺序签署**会让他们一步一步地被邀请。参见 [参与方、角色与签署顺序](parties.md) 和 [身份验证](identification.md)。

### 字段

在**字段**选项卡中选择一位参与方，然后在页面上放置字段。字段也可以来自文件本身：[文本标签](text-tags.md#text-tags)（例如 `{{Sign;type=signature;role=Tenant}}`）和[可填写 PDF 表单](text-tags.md#pdf-forms)的字段会在上传时变成字段，**字段**选项卡中的[检测字段](text-tags.md#detect-fields)会在页面上有横线和方框待填写的位置建议字段。每个字段属于一位参与方，由其在签署时填写。选中一个字段，即可在**字段**面板中修改它：由谁填写、标签、是否必填，以及下面的设置。

| 字段 | |
| --- | --- |
| 签名 | 手写或输入的签名。 |
| 姓名缩写 | 参与方姓名的缩写。 |
| 文本 | 自由文本。可以设置格式、长度和默认值。 |
| 数字 | 一个数字，带最小值和最大值，以及[格式](#number-and-date-formats)。 |
| 下拉列表 | 从选项列表中选择一项。 |
| 多选 | 从列表中选择任意数量的选项，在页面上以逗号分隔写出。 |
| 单选按钮 | 一组按钮，参与方从中选择一个。参见[单选按钮组](#radio-groups)。 |
| 复选框 | 可以设为必填，或默认勾选。 |
| 电话 | 带国家代码的电话号码，存储为 +46701234567。 |
| 日期选择器 | 参与方从日历中选择的日期，带最早和最晚日期，以及[格式](#number-and-date-formats)。 |
| 图片 | 参与方上传图片或拍照。图片会被缩放并绘制到方框内。 |
| 文件 | 参与方在页面上直接上传 PDF、JPEG 或 PNG。文件名写在方框中，文件会被封存进已签署的 PDF，与[附件](attachments.md)一样。 |
| 公式 | 由其他字段算出的数字，例如含增值税的总额。参见[公式](#formulas)。 |
| 日期 | 自动填入签署日期，格式由你选择。 |
| 姓名、邮箱、公司 | 根据参与方的详细信息自动填入。 |

在**字段**选项卡中选择**我，现在（预填）**，可以放置一个由你在发送前自己填写的值，例如合同编号、金额或日期。这类必填字段必须先填写，文档才能发送。

参与方的文本、数字、列表、单选按钮、复选框、电话和日期字段可以设置**默认值**作为起始值。开启**只读**后，他们能看到该值但不能更改。

#### 检查与错误提示

检查会在参与方输入时于签署页面上运行，并在其签署时于服务器上再次运行，因此违反检查的值永远不会进入封印后的 PDF。

| 检查 | 适用于 | |
| --- | --- | --- |
| 允许的格式 | 文本、姓名缩写、公司 | 预设格式（邮箱地址、仅数字、瑞典邮政编码、个人身份号码或组织号码），或你自己的正则表达式。整个值都必须匹配。 |
| 最短长度、最长长度 | 文本、姓名缩写、公司 | 以字符计。 |
| 最小值、最大值 | 数字 | 含边界值。 |
| 最早、最晚 | 日期选择器 | 含边界值。 |
| 必填 | 参与方填写的每个字段 | |

**错误提示**会用你自己的文字替换该字段上任何检查的内置错误，例如 *Write the order number as AB1234*。没有设置时，参与方会看到用其自己语言写的内置错误。

模式使用常见的正则表达式语法：诸如 `[0-9]` 和 `\d` 的字符类，诸如 `{3}`、`+` 和 `?` 的重复，用 `|` 表示的选择，以及分组。不支持先行断言和反向引用，这样可以保证每次检查都很快。

#### 数字与日期格式

格式决定值在页面上如何书写；存储的内容保持朴素（`1234.5`、`2026-12-31`），因此导出和 API 得到的永远是同样的形式。

数字格式按 1234 在其中的样子来书写。`1,234.00` 表示千位用逗号分隔并保留两位小数，`1 234,00 kr` 表示用空格分隔、小数点用逗号、货币符号在后，`$1234` 表示不带小数并带美元符号。值按格式的小数位数四舍五入。参与方两种写法都可以输入，例如 `1 234,5` 或 `1,234.50`。

日期可以写成 YYYY-MM-DD、DD/MM/YYYY、MM/DD/YYYY、DD.MM.YYYY 或 D MMM YYYY（31 Dec 2026）。签署日期也适用同样的格式。

#### 单选按钮组

放置**单选按钮**会添加一个按钮。选中它，为每个额外的选项选择**向组中添加按钮**，然后把按钮拖到合适的位置。每个按钮代表一个选项；整个组共用标签以及是否必须作答。参与方可以在组内选择一个按钮。

#### 条件字段

在字段面板的**仅在以下情况显示**下，添加针对其他字段的条件。只有当它们全部成立时，该字段才会显示，例如仅当*类型*为*公司*时才显示*组织号码*，或仅当勾选了*其他*复选框时才显示*原因*框。带条件的字段在编辑器中以虚线边框绘制。

| 规则 | |
| --- | --- |
| 等于、不等于 | 与选项、数字或文本比较。文本比较时不区分大小写，数字按值比较，所以 10 和 10.0 相同。 |
| 已填写、为空 | 对于复选框：已勾选、未勾选。 |
| 包含 | 多选列表中勾选了该选项，或文本包含这些词。 |
| 大于、小于 | 用于数字，以及日期（晚于、早于）。 |

隐藏的字段永远不是必填的，参与方签署时它保持为空，也不会写入已签署的 PDF。依赖于隐藏字段的字段会把它看作空，因此隐藏会逐级传递。

条件通过标签引用字段，所以你所指向的字段需要有标签，并且只能有一个字段使用该标签。在编辑器中重命名字段时，会更新使用它的条件和公式。参与方的字段可以参照其自己的字段、你预填的值，以及在**按顺序签署**开启时更早签署的参与方的字段。参与方签署时，服务器会再次检查条件，所以参与方无法通过修改页面来跳过某个字段。

#### 公式

**公式**字段会在参与方填写文档时，根据其他字段算出一个数字。参与方能看到结果但不能更改，并且在其签署时服务器会根据提交的值重新计算，因此存储的结果是可信的。为它指定一个[数字格式](#number-and-date-formats)来取整并书写，例如 `1 234,00 kr`。

把其他字段的标签写在大括号中，并使用 `+ - * /`（或 `× ÷`）、括号以及下列函数：

| 函数 | |
| --- | --- |
| `round(x, 2)` | 四舍五入到 0 至 6 位小数；不给第二个值时，取整数。 |
| `floor(x)`、`ceil(x)`、`abs(x)` | 向下取整、向上取整，或去掉符号取绝对值。 |
| `min(a, b, …)`、`max(a, b, …)`、`sum(a, b, …)` | |
| `if(condition, then, else)` | 条件用 `=`、`!=`、`<`、`<=`、`>` 和 `>=` 比较，并可用 `and(…)`、`or(…)` 和 `not(…)` 组合。 |
| `contains(list, "text")` | 多选列表中是否勾选了该选项，或文本是否包含这些词。 |

示例：

- 价格的增值税：`{Price} * 0.25`
- 含增值税的总额：`round({Hours} * {Rate} * 1.25, 2)`
- 超过某金额的折扣：`if({Amount} >= 10000, {Amount} * 0.05, 0)`
- 按套餐定价：`if({Plan} = "Pro", 99, 49) * {Seats}`

空字段按 0 计，勾选的复选框按 1 计。除以零或使用了不是数字的文本的公式，结果保持为空。由你自己填写的公式只能使用你自己预填的字段，并在保存时计算；参与方的公式可以使用与[条件](#conditional-fields)相同的字段。

字段以页面比例的分数存储，所以无论页面尺寸如何，它们都保持在原位。

## 发送之前

**审阅**面板会在你操作时检查文档的设置，并列出任何会妨碍签署或削弱结果的问题：

- 错误，会阻止发送：没有文件、没有签署人或审批人、通过邮件或短信接收链接的参与方没有邮箱地址或电话号码、必须用短信验证码确认的参与方没有电话号码、查看者带有要填写的字段、必填的发送人字段为空。
- 警告，值得一看：签署人没有签名字段（其签名只会出现在证据页上）、电子身份验证的参与方没有个人身份号码（因此任何拿到链接并拥有电子身份的人都可以签署）、参与方既没有邮箱也没有电话（因此他们收不到已签署的副本）。

如果管理员已设置 AI，同一面板还可以请 AI 阅读文档。参见 [AI 助手与审阅](ai.md#document-review)。

## 预览

**发起签署**旁边的**预览**会显示所选参与方将看到的签署页面，包含其字段、语言和身份验证步骤。参见 [签署页面](signing-page.md#previewing-as-a-party)。

## 签署人的 AI 审阅

默认情况下，签署人可以把文档的只读副本交给自己的 AI 助手，在签署前请它解释。在**签署人的 AI 审阅**下关闭**允许签署人与其 AI 分享**即可禁止。参见 [签署页面](signing-page.md#review-with-your-ai)。

## 发送

选择**发起签署**。OpenSign 会把文件合并为一份 PDF 并锁定，然后通知第一批参与方。对于投递方式为**链接**的参与方，OpenSign 会显示**交付签署链接**，并附上每个可复制的链接。你之后可以在参与方卡片上获取新链接，**新链接**会先撤销旧链接。

## 等待期间

在文档页面你可以：

- **提醒**所有轮到签署但尚未签署的人。
- 获取或替换参与方的签署链接。
- 为在你的设备上签署的参与方开始**当面签署**。参见 [当面签署](in-person.md)。
- **取消**文档，可附上原因。所有签署链接都会失效，已收到通知的参与方会被告知。
- 查看**动态**：文档审计日志中的每一步，例如谁打开、验证身份、签署或下载了它。

## 完成之后

最后一位参与方签署后，OpenSign 会在后台封印文档，通常在几秒内完成。随后文档页面会提供封印后的 PDF 和发送时的原件。有邮箱地址的参与方也会收到封印后的 PDF。参见 [封印 PDF 与证据](sealed-pdfs.md)。

每次下载都会记录在审计日志中。

要以数据形式获取参与方填写的内容，请在**⋯**菜单中选择**导出数据**。参见 [导出已填写的数据](data-export.md)。

## 与同事分享

文档属于创建它的人。要让同事看到一份文档，请与他们分享，也可以允许他们修改。经理、审计员和管理员无需分享就能看到每一份文档。参见 [用户与角色](users-and-roles.md)。

## 删除

不处于等待中的文档可以连同其文件一起删除。等待中的文档请先取消。已签署的文档只有管理所有文档的人才能删除，处于法律保全的文档任何人都不能删除。删除会记录在审计日志中。文档也可以由保留规则自动删除。参见 [保留与法律保全](retention.md)。

## 查找文档

**文档**页面按最新优先列出你能看到的文档，并按状态分标签页。可以按标题或你的编号搜索。

从列表旁的文件夹列把文档整理到文件夹中，并归档已完成的文档，使其不再出现在状态标签页中。**已归档**标签页会列出它们。参见 [文件夹与归档](folders.md)。
