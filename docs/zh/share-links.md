# 共享链接与二维码

共享链接让任何人都可以自行从模板发起文档：网站上的会员表单、前台的免责声明、印成海报上二维码的同意书。打开链接的人提供姓名和邮箱，用验证码确认邮箱，然后签署自己的副本。对于未经确认的地址，不会生成任何内容。

## 开启共享链接

1. 打开模板。你需要有修改它和发送文档的权限。
2. 在**公开链接**下，开启**通过链接或二维码分享**。
3. 在**由访问者填写**中，选择打开链接的人将成为的模板参与方，例如“客户”。该参与方必须是签署或审批。其他每位参与方保持模板中的样子，所以你这一方的会签人仍会在其之后签署。
4. 复制链接，或选择**二维码**并下载为 PNG（用于屏幕和文档）或 SVG（用于印刷）。

链接形如 `https://sign.example.com/s/Xq3…`。开启之前它是关闭的，关闭后立即失效。通过该链接创建的文档以开启它的用户的名义发送，并出现在其文档列表中，标题由模板名称和访问者姓名组成。

共享链接需要先设置好邮件，因为每位访问者都要确认自己的地址。参见 [设置](settings.md)。

## 访问者看到什么

1. 一个起始页，显示你的徽标、模板的标题和留言，使用模板的语言。他们可以切换到任何[11 种签署语言](signing-page.md#languages)。
2. 他们输入姓名和邮箱（当参与方通过短信接收验证码或短信链接时，还要输入电话号码）。姓名只能包含字母，不能含数字或地址，因为它会进入文档标题和相关邮件。链接所产生的文档的短信计入 [身份验证](identification.md) 中的短信限额。
3. OpenSign 会给他们发一封邮件，内含有效期 15 分钟的六位数验证码。他们输入该验证码。
4. OpenSign 根据模板生成文档，把他们作为该参与方并发送。签署页面会立即打开；同一个链接也会通过邮件发给他们，以便稍后再回来。

如果在按顺序签署的文档中还有其他参与方排在他们之前签署，他们会被告知，轮到自己时会收到邮件。

模板参与方上设置的身份验证仍然适用。如果该参与方必须用 BankID 或短信验证码验证身份，访问者会像任何签署人一样在签署页面上完成。参见 [身份验证](identification.md)。

## 限制

每个链接都有你在**公开链接**下设置的限制：

| 限制 | 作用 |
| --- | --- |
| **每小时** | 每小时最多生成这么多份文档（1 到 1000，默认 10）。 |
| **总计** | 总共最多生成这么多份文档。留空表示不限。 |
| **最后一天** | 过了这一天，链接就停止工作。 |

除此之外，OpenSign 还会自行保护每个链接：

- 每个地址每小时最多收到 3 个验证码，每个链接发送的验证码最多为其每小时限额的三倍（至少 20 个），因此链接不会被用来向某人的收件箱狂发邮件。
- 一个验证码允许尝试 5 次，且只能使用一次。
- 与签署页面一样，起始页上以及请求或输入验证码时，每个 IP 地址都有速率限制。
- 未确认的请求会在一天后被删除。

## 更换地址

**新地址**会给链接一个新地址。旧地址以及由它印出的每个二维码会立即失效。当链接的传播范围超出你的预期时，请使用它。

## 通过 API

- `GET /api/v1/templates/{templateId}/share-link`：链接、它的限制，以及它生成了多少份文档。
- `PUT /api/v1/templates/{templateId}/share-link`，带上 `enabled`、`partyId`、`perHour`、`maxTotal` 和 `expiresAt`。
- `POST /api/v1/templates/{templateId}/share-link/rotate`：新地址。

这些同时也是 MCP 工具（`share_links_get`、`share_links_set`、`share_links_rotate`）。参见 [REST API](api.md) 和 [MCP](mcp.md)。

通过共享链接生成的文档会触发 `document.created`，带有 `"source": "share_link"` 以及该链接的 `shareLinkId`。参见 [Webhook](webhooks.md#events)。

## 会记录什么

模板的审计日志会记录对链接的每一次更改、发出的每个验证码（连同邮箱地址）以及生成的每份文档。新文档的审计日志始于它由共享链接创建。
