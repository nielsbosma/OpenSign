# Документация OpenSign

OpenSign — это электронная подпись с открытым исходным кодом, которую вы запускаете у себя. Вы загружаете документ Word или PDF, расставляете поля и отправляете. Каждый подписант получает ссылку, подтверждает свою личность выбранным вами способом и подписывает. Когда все закончат, вы получаете запечатанный PDF, который проверяется в любой программе для чтения PDF, со страницами доказательств: кто подписал, когда и как подтвердил личность.

Эта документация показывается на вашем языке, а сменить его можно в меню языка вверху. Переводы выполнены машинным способом, основным текстом считается английская версия.

Эти страницы охватывают все возможности OpenSign: для тех, кто отправляет документы, для администраторов, которые отвечают за установку, и для разработчиков, которые интегрируются с системой.

## Что умеет OpenSign

- **Процессы подписания.** Подписанты, согласующие и наблюдатели — в заданном порядке или все сразу. Ссылки уходят по электронной почте или в SMS, вы передаёте их сами, или подписант расписывается лично на вашем устройстве. Напоминания, сроки действия и отказ с указанием причины уже встроены. См. [Участники, роли и порядок подписания](parties.md).
- **Идентификация.** Ссылка из письма, код из SMS, шведский BankID (по собственному договору с банком или через TIC Identity), Freja eID и другие скандинавские eID через брокер OpenID Connect. Если у участника указан личный номер, подписать может только этот человек. См. [Идентификация](identification.md).
- **Шаблоны и массовая отправка.** Сохраните подготовленный документ как шаблон и отправьте его по каждой строке файла CSV или Excel. См. [Шаблоны](templates.md) и [Массовая отправка](bulk-send.md).
- **Вложения подписантов.** Попросите участника прислать файлы, например копию удостоверения личности: они очищаются и запечатываются в подписанный PDF. См. [Вложения подписантов](attachments.md).
- **Запечатанные PDF.** Печати PAdES B-LTA с меткой времени RFC 3161 и всем необходимым, чтобы файл можно было проверить офлайн в течение многих лет. См. [Запечатанные PDF и доказательства](sealed-pdfs.md).
- **Папки и архив.** Раскладывайте документы и шаблоны по общим папкам и архивируйте завершённую работу, чтобы списки оставались короткими. См. [Папки и архив](folders.md).
- **Хранение и юридическое удержание.** Удаляйте документы автоматически по истечении заданного срока, а важные сохраняйте с помощью юридического удержания. См. [Хранение и юридическое удержание](retention.md).
- **Пользователи и роли.** Администратор, менеджер, отправитель, аудитор и наблюдатель; для двухфакторного входа — ключи доступа или приложение-аутентификатор. См. [Пользователи и роли](users-and-roles.md).
- **API.** REST API с OpenAPI, готовые конечные точки, совместимые со Scrive и DocuSign, подписанные вебхуки и сервер MCP для Claude и других ИИ-клиентов. См. [REST API](api.md).
- **ИИ — если он вам нужен.** Ассистент и проверка документов перед отправкой. Выключено, пока администратор не выберет провайдера. См. [ИИ-ассистент и проверка](ai.md).
- **Безопасность прежде всего.** Шифрование на диске, защищённый от подделки журнал аудита, строгие заголовки веб-безопасности и проверка прав на сервере при каждом вызове. См. [Модель безопасности](security.md).

## Как всё устроено

OpenSign — это один образ контейнера. Ему нужны Postgres, хранилище, совместимое с S3, и, если вы хотите принимать файлы Word, конвертер Gotenberg в закрытой сети. Веб-приложение, API, сервер MCP и фоновый обработчик работают в одном образе и используют одни и те же сервисы, поэтому право или правило действует одинаково, как бы ни пришёл запрос.

```
           ┌──────────────── one container ───────────────────────────┐
 browser ─▶│ React app ─ RPC ──┐                                      │
 REST/API ▶│ REST, Scrive,     ├─▶ services (permissions, audit, ──▶ Postgres
 Claude  ─▶│ DocuSign, MCP ────┤   settings, encryption)          ──▶ S3 (encrypted files)
 signer  ─▶│ signing page ─────┘   worker: email, SMS, sealing,   ──▶ Email, SMS, eID, TSA, LLM
           │                       webhooks, reminders            ──▶ Gotenberg (private)
           └──────────────────────────────────────────────────────────┘
```

OpenSign распространяется по лицензии MIT. Исходный код находится на [GitHub](https://github.com/nielsbosma/OpenSign).
