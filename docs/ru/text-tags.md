# Текстовые теги, импорт форм и поиск полей

Не обязательно перетаскивать каждое поле на страницу. OpenSign умеет читать поля из самого файла тремя способами:

- **Текстовые теги**, которые вы пишете в файле Word или PDF, например `{{Tenant Sign;role=Tenant;type=signature}}`.
- **PDF-формы**: поля заполняемого PDF становятся полями OpenSign вместе со значениями, которыми они были заполнены.
- **Найти поля** в редакторе предлагает поля там, где на странице есть линии, подчёркивания или рамки для заполнения.

Поля, созданные любым из этих способов, — обычные поля. Перед отправкой их можно перемещать, менять размер, изменять или удалять.

## Текстовые теги

Напишите тег в тексте документа там, где должно быть поле. При загрузке файла OpenSign превращает каждый тег в поле на месте тега и убирает текст тега со страницы, так что подписанты его не видят. Остальная часть строки остаётся там же, где была.

Синтаксис такой же, как у DocuSeal, поэтому шаблоны, созданные для DocuSeal, работают без изменений:

```
{{Field Name;role=Tenant;type=signature;required=false}}
```

Первая часть — имя поля, которое показывается как его метка. После неё идут атрибуты вида `key=value`, разделённые точками с запятой. В теге можно опустить имя и начать с атрибута, например `{{type=checkbox}}`.

| Атрибут | |
| --- | --- |
| `type` | Вид поля, см. ниже. Если не указан, то `text`. |
| `role` | Участник, который его заполняет, по имени, например `Tenant` или `Landlord`. Роль, которой в документе ещё нет, добавляется как новый участник; заполните его данные перед отправкой. Без роли поле достаётся первому подписывающему участнику. |
| `required` | `false` делает поле необязательным. Поля по умолчанию обязательные, флажки — нет. |
| `readonly` | `true` показывает значение по умолчанию участнику, не позволяя его изменить. |
| `default` | Значение, с которого участник начинает. |
| `title` | Метка, отличная от имени. |
| `options` | Варианты поля `select` или `multiple`, через запятую (или через `|`). |
| `option` | Единственный вариант, который означает кнопка `radio`. Теги `radio` с одним именем образуют одну группу. |
| `format` | Формат даты, например `DD/MM/YYYY` или `MM/DD/YYYY`, или формат числа: `usd`, `eur`, `gbp`, `sek` либо вид, в котором выглядело бы 1234, например `1 234,00 kr`. См. [Форматы чисел и дат](documents.md#number-and-date-formats). |
| `min`, `max` | Наименьшее и наибольшее число либо самая ранняя и самая поздняя дата в виде YYYY-MM-DD. |
| `width`, `height` | Размер поля в пунктах (1/72 дюйма). Без них поле имеет ширину тега и высоту его текста, а подписи, инициалы и изображения получают разумный минимум и растут вверх от линии. |

| Тип | Поле |
| --- | --- |
| `text` | Текст |
| `signature` | Подпись |
| `initials` | Инициалы |
| `date` | Выбор даты |
| `datenow` | Дата подписания, заполняется автоматически |
| `number` | Число |
| `select` | Раскрывающийся список |
| `multiple` | Множественный выбор |
| `radio` | Одна кнопка-переключатель |
| `checkbox` | Флажок |
| `phone` | Телефон |
| `image`, `file` | Загрузка изображения или файла |
| `name`, `email`, `company` | Заполняются из данных участника (только в OpenSign) |

Примеры:

```
{{Client Name;role=Client}}
{{Client Sign;type=signature;role=Client}}
{{Start Date;type=date;format=DD/MM/YYYY;role=Client}}
{{Region;type=select;options=North,South,East,West}}
{{Plan;type=radio;option=Basic}} Basic   {{Plan;type=radio;option=Plus}} Plus
{{type=checkbox;role=Client}} I accept the terms
{{Amount;type=number;format=sek;min=0}}
```

Тег, который нельзя использовать, остаётся на странице как текст, а при загрузке OpenSign сообщает почему: тип, которого в OpenSign нет (например, `payment`, `stamp` или `verification` из DocuSeal), атрибут без значения, значение, которое поле не принимает, или тег, разорванный на две строки. Атрибуты, которые OpenSign не использует, например шрифты и цвета, игнорируются.

### Как писать теги в Word

Вводите теги как обычный текст. Держите каждый тег в одной строке: сократите имя или уменьшите шрифт, если Word переносит его. Размер шрифта тега определяет высоту поля, поэтому тег, набранный 8-м кеглем, даёт невысокое поле. Текстовые теги работают в файлах Word, OpenDocument и RTF на установках с конвертером документов, а также в любом PDF, текст которого можно прочитать. У отсканированных страниц нет текста, поэтому в них нет и тегов.

### Как отключить теги

Теги читаются при каждой загрузке. Чтобы загрузить файл, в тексте которого случайно встречаются `{{` и `}}`, отключите их через API параметром `textTags=false`. API [Scrive](scrive.md) и [DocuSign](docusign.md) теги никогда не читают.

## PDF-формы

Заполняемая PDF-форма (AcroForm) становится полями при загрузке: текстовые поля — текстовыми полями, флажки — флажками, переключатели — группой переключателей, списки — раскрывающимися списками или множественным выбором, а поля подписи — полями подписи. Значения, которыми форма была заполнена, становятся значениями по умолчанию, а поля, помеченные в форме как обязательные, остаются обязательными.

Поле формы, имя которого начинается с имени участника, достаётся этому участнику: `Tenant.Name` и `Tenant name` достаются Tenant. Остальные достаются первому подписывающему участнику. Сама форма, как и при любой загрузке, всё равно удаляется из файла, так что остаются только поля OpenSign. Формы XFA не читаются.

## Найти поля

**Найти поля** на панели инструментов полей просматривает страницы в поисках мест, которым нужно поле:

- линии и ряды подчёркиваний, на которых пишут, с меткой рядом или под ними,
- пустые рамки для отметки, с текстом рядом в качестве метки.

Вид поля определяет метка: Signature, Underskrift или Firma становится полем подписи, Name или Namnförtydligande — именем, Date или Datum — датой подписания, Date of birth — выбором даты, Email, Phone и Company — соответствующими полями, а всё остальное — текстом.

Предложения рисуются пунктирными рамками, и ничего не сохраняется, пока вы их не примете. Нажмите на предложение, чтобы добавить его, или **Принять все**. Они достаются участнику, выбранному на панели инструментов; подписи и инициалы достаются подписанту. Наведите курсор на предложение и нажмите крестик, чтобы отклонить его. Места, где поле уже есть, повторно не предлагаются.

### С помощью ИИ

Если настроен [ИИ-провайдер](ai.md) и включено **Разрешить отправку текста документов на проверку**, то **Найти поля** предлагает также **Также с ИИ**. Тогда OpenSign отправляет модели текст каждой страницы с его положением и места, которые уже найдены, и добавляет предложения модели, отмеченные искрой. Изображения он не отправляет, не более 30 страниц и около 40 000 символов, а вызов учитывается в бюджете ИИ. Каждое обнаружение с помощью ИИ записывается в [журнал аудита](audit-log.md).

## Через API

`POST /api/v1/documents/{id}/files` и `documents.upload` читают текстовые теги и поля форм, если `textTags` или `formFields` не равны `false`. В поле `fields` ответа указано, сколько полей создано из каждого источника, какие участники добавлены и какие теги не удалось использовать.

`documents.detect_fields` возвращает предложения для черновика, ничего не сохраняя. Передайте `ai: true`, чтобы дополнительно спросить модель ИИ. Нужные поля разместите с помощью `documents.set_fields`. См. [API](api.md).
