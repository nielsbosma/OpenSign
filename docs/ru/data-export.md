# Экспорт заполненных данных

То, что подписанты вводят в поля, попадает в запечатанный PDF, а ещё это можно получить в виде данных: как таблицу, как JSON, через API или от ИИ-агента по MCP.

## Из приложения

Выберите **Экспорт данных**, затем **Excel**, **CSV** или **JSON**:

- На странице **Документы**, рядом с **Новый документ**. Экспорт содержит документы, которые показывает список: выбранные вами вкладку статуса, папку, поиск и вкладку архива, а не только видимую страницу.
- Если на странице **Документы** выбраны строки, то в разделе **Действия** — только для этих документов.
- В шаблоне, в меню **⋯**, — для каждого документа, созданного из него.
- В массовой отправке — для каждого документа, который она создала.
- В документе, в меню **⋯**, — для этого одного документа.

В один экспорт входит до 5000 документов. Чтобы экспортировать больше, сузьте фильтры и выгружайте по частям.

## Что в нём содержится

В таблице по одной строке на документ, сначала самые старые:

| Столбцы | |
| --- | --- |
| Document ID, Title, Reference, Status | Документ. Reference — это ваш **Ваш номер**. |
| Created, Sent, Completed | Время в UTC. |
| Party 1 Name, Party 1 Email, Party 1 Signed | Каждый участник в порядке подписания, затем Party 2 и так далее. |
| По столбцу на поле | Названы по метке поля. |

Значения полей записываются так, как их хранит OpenSign, поэтому их можно сортировать и суммировать в таблице:

| Поле | Значение |
| --- | --- |
| Число | Простое число, например `1234.5`, независимо от формата отображения поля. В Excel это настоящее число. |
| Формула | Число, вычисленное сервером, как для числового поля. |
| Выбор даты и дата подписания | `YYYY-MM-DD`. |
| Флажок | `true` или `false`. В Excel — настоящие TRUE или FALSE. |
| Раскрывающийся список и группа переключателей | Выбранный вариант. Группа переключателей — один столбец с названием по метке группы. |
| Множественный выбор | Выбранные варианты через запятую (список в JSON). |
| Телефон | Номер с кодом страны, например `+46701234567`. |
| Изображение и загрузка файла | Имя файла. Сам файл не экспортируется; скачайте его со страницы документа. |
| Подпись | Не включается: столбец Signed участника сообщает, когда он подписал. |

Поле, которое ещё не заполнено, пусто, поэтому можно экспортировать и ожидающие документы. Пусто также поле, скрытое условием на момент подписания.

### Названия столбцов

Столбец называется по метке поля или, если метки нет, по его виду. Если у участников есть поля с одинаковой меткой, например поле «Имя» у каждого, добавляется участник: `Name (Party 1)`, `Name (Party 2)`. Метка, использованная дважды одним участником, получает номер: `Note`, `Note (2)`. Давайте полям в шаблоне понятные и уникальные метки, и столбцы последуют за ними.

При экспорте документов из разных шаблонов каждая метка поля становится столбцом, а в документе без такого поля он остаётся пустым.

## Безопасность

- Экспортируются только документы, которые вы можете видеть. Те, у кого нет доступа ко всем документам, экспортируют свои и предоставленные им.
- Для экспорта нужно право `documents.export`, которое есть у администраторов, менеджеров, отправителей и аудиторов. Наблюдатели могут видеть значения предоставленного документа на его странице, но экспортировать не могут. См. [Пользователи и роли](users-and-roles.md#permissions).
- Личные номера никогда не экспортируются, а загруженные файлы перечисляются только по имени.
- К ячейке CSV, начинающейся с `=`, `+`, `-` или `@`, спереди добавляется `'`, чтобы таблица показывала её как текст, а не выполняла как формулу. Иначе подписант мог бы ввести в поле `=HYPERLINK(…)` и запустить это на вашем компьютере. Отрицательные числа не затрагиваются. Файлы Excel записывают текст как текст, поэтому там ничего менять не нужно.
- Файлы CSV — это UTF-8 с меткой порядка байтов, чтобы Excel правильно показывал å, ü и 中.
- Каждый экспорт записывается в [журнал аудита](audit-log.md) как `documents.exported` с форматом, фильтрами и документами, которые в него вошли.

## Через API

Значения одного документа, с типами:

```sh
curl https://sign.example.com/api/v1/documents/$ID/values -H "Authorization: Bearer $KEY"
```

```json
{
  "id": "019a2b11-5d0e-7a42-b6f3-1c9e0d7a4f28",
  "title": "Lease, Storgatan 1",
  "status": "completed",
  "parties": [{ "id": "…", "slot": "Party 1", "role": "signer", "name": "Anna Berg", "email": "anna@example.com", "signedAt": "2026-10-29T10:12:00Z", "…": "…" }],
  "fields": [{ "key": "Monthly rent", "label": "Monthly rent", "kind": "number", "partyId": "…", "fieldIds": ["…"], "value": 12500 }],
  "values": { "Monthly rent": 12500, "Pets": "No", "Rooms": ["Kitchen", "Bath"], "Agree to terms": true }
}
```

`values` — самый быстрый путь: ключи полей, сопоставленные значениям с типами. `fields` содержит те же значения вместе с идентификаторами полей, видами и участниками. Чтение значений требует только доступа к документу и не попадает в аудит, как и открытие документа.

Много документов сразу:

```sh
curl -X POST https://sign.example.com/api/v1/exports -H "Authorization: Bearer $KEY" \
  -H "content-type: application/json" -d '{"format": "xlsx", "templateId": "…", "status": "completed"}'
```

Тело принимает `format` (`csv`, `xlsx` или `json`) и любые из `ids`, `templateId`, `bulkId`, `status`, `search`, `folderId` и `archived` (`true` — только архивные документы, `false` — исключить их, не указан — и те и другие). В ответе есть `name`, `contentType` и `count`, а также `contentBase64` для CSV и Excel или `documents` (каждый в описанном выше виде) для JSON.

Клиенты DocuSign получают те же значения через `GET /envelopes/{id}/form_data`; см. [API DocuSign](docusign.md).

Оба вызова также доступны как инструменты MCP, `documents_values` и `documents_export`, так что агент может ответить на вопрос «сколько арендаторов в этом месяце согласились на домашних животных?» См. [MCP](mcp.md).

## С вебхуками

Событие `document.completed` содержит `valuesUrl` — адрес `/values`, описанный выше, так что интеграция может получить всё, что ввели подписанты, одним вызовом. Сами вебхуки никогда не содержат значений полей. См. [Вебхуки](webhooks.md#events).
