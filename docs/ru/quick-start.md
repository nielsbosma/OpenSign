# Быстрый старт

Эта страница проведёт вас от нуля до подписанного документа на вашем компьютере. Для боевой установки дальше читайте [Развёртывание](deployment.md).

## 1. Запустите OpenSign локально

Вам нужны Docker и копия репозитория.

```sh
git clone https://github.com/nielsbosma/OpenSign.git
cd OpenSign
docker compose up -d --wait postgres s3 mailpit converter
docker compose run --rm s3-init
docker compose --profile prod up -d --build
```

Первые две команды запускают Postgres, S3-совместимое хранилище, Gotenberg для файлов Word и Mailpit, а также создают бакеты. Последняя собирает и запускает боевой образ.

- OpenSign: http://localhost:8090
- Mailpit, локальный почтовый ящик для разработки: http://localhost:8026

Боевой образ отправляет настоящие письма, поэтому ему нужна настоящая учётная запись электронной почты (шаг 3). Чтобы попробовать OpenSign без неё, запустите его в режиме разработки: там все письма попадают в Mailpit:

```sh
pnpm install
pnpm infra:up
cp .env.example .env
pnpm dev            # web app on http://localhost:5173
```

## 2. Создайте первого администратора

Новая установка выводит в журнал **код настройки**, чтобы никто другой не успел занять её раньше вас.

```sh
docker compose logs app | grep "setup code"
```

В режиме разработки он находится в терминале, где запущен `pnpm dev`.

Откройте OpenSign и введите код настройки, своё имя, организацию, адрес электронной почты и пароль. Что делает каждый шаг, описано в разделе [Первая настройка и электронная почта](setup.md).

## 3. Подключите электронную почту

OpenSign отправляет приглашения, коды и подписанные документы по электронной почте, поэтому до начала отправки он просит указать почтового провайдера. Введите ключ API Resend и адрес отправителя на домене, который вы подтвердили в Resend. OpenSign пришлёт вам тестовое письмо и продолжит, только когда оно уйдёт.

В режиме разработки ключ можно оставить пустым: тестовое письмо и всё последующее попадёт в Mailpit.

## 4. Отправьте документ

1. Откройте **Документы** и нажмите **Новый документ**.
2. Перетащите файл PDF или Word, укажите название и создайте документ.
3. В разделе **Участники** добавьте себя как подписанта со своим адресом электронной почты.
4. Выберите участника на панели инструментов полей и поместите на страницу поле **Подпись**.
5. Нажмите **Отправить на подпись**.

Откройте приглашение, перейдите по ссылке, нарисуйте или введите подпись и подпишите. Через несколько секунд документ получит статус **Подписан**, и запечатанный PDF можно будет скачать на странице документа.

## 5. Проверьте результат

Откройте **Проверить документ** на боковой панели (или перейдите на `/verify`) и перетащите запечатанный PDF. OpenSign проверит печать и метки времени и подтвердит, что запечатал именно этот файл. Программа для чтения PDF с поддержкой подписей, например Adobe Acrobat, тоже покажет печать.
