# Массовая отправка

Массовая отправка отправляет [шаблон](templates.md) по каждой строке таблицы. Каждая строка становится отдельным документом со своими участниками и значениями полей, который отправляется и отслеживается отдельно: новый договор аренды для каждого арендатора, обновление политики для каждого сотрудника.

## Перед началом

- Подготовьте шаблон с нужными участниками, полями, сообщением и идентификацией.
- Подготовьте файл CSV или Excel (`.xlsx`). Старые файлы `.xls` и OpenDocument `.ods` сначала сохраните как `.xlsx`. Первая строка задаёт названия столбцов. До 1000 строк и 5 МБ.
- Вам нужно право отправлять документы.

## Отправка

1. Откройте шаблон и выберите **Массовая отправка** в его меню.
2. Выберите файл. OpenSign прочитает его и покажет каждый столбец с первым значением и тем, что он **Заполняет**.
3. Проверьте сопоставление. Измените цель любого столбца или выберите **Пропустить**.
4. При желании задайте **Названия документов** — шаблон с именами столбцов в фигурных скобках, например `Lease {Address}`. Если пусто, используются название шаблона и имя первого участника.
5. Исправьте строки, которые OpenSign перечислит в разделе **Исправьте эти строки перед отправкой**.
6. Отправьте. OpenSign создаст и отправит документы в фоновом режиме и откроет страницу хода массовой отправки.

## Что может заполнять столбец

| Цель | |
| --- | --- |
| Имя, Эл. почта, Мобильный, Компания или Личный номер участника | По одному набору для каждого участника шаблона. |
| Поле | Любое поле шаблона с меткой, заполняется как значение отправителя для этой строки. Числа можно записывать любым способом (`1 234,50` или `1,234.50`), даты — как YYYY-MM-DD или в формате поля, поля-списки — по тексту варианта, а несколько вариантов — через запятую. Значение, нарушающее проверки поля, приводит к ошибке в этой строке. |
| Название | Название документа вместо шаблона. |
| Ваш номер | Внешний идентификатор документа, например номер клиента. |
| Язык участника | Язык писем и страницы подписания этого подписанта в виде кода, например `sv` или `pt-BR`. См. [Страница подписания](signing-page.md#languages). |

## Сопоставление столбцов

OpenSign сопоставляет столбцы по названию, на английском и шведском. Например, «Email», «E-post» и «Mail» подходят к адресу электронной почты участника, а «Mobile», «Mobil» и «Telefon» — к мобильному номеру. Если в шаблоне несколько участников, столбец, начинающийся с имени участника, например «Guarantor email», достаётся этому участнику.

Если администратор настроил ИИ, вы можете поручить ему сопоставить столбцы, которые встроенные правила не распознали. Ему отправляются названия столбцов. Он также получает несколько строк-образцов, но только если администратор разрешил отправлять текст документов ИИ-провайдеру. См. [ИИ-ассистент и проверка](ai.md).

## Проверка строк

Перед отправкой проверяется каждая строка: у каждого участника должно быть имя, правильный адрес электронной почты, если он получает ссылку по почте, правильный мобильный номер, если он получает её по SMS, и так далее. Если хоть одна строка не пройдёт, ничего не отправляется, а OpenSign перечисляет проблемы по номерам строк таблицы. Исправьте файл и выберите его снова.

## Ход выполнения

Страница массовой отправки показывает каждую строку с получателем, статусом и ссылкой на созданный документ. **Массовые отправки** внизу страницы **Шаблоны** перечисляют последние запуски.

**Остановить** пропускает строки, которые ещё не отправлены. Уже отправленные документы остаются на подписании; при необходимости отмените их по одному.

**Экспорт данных** скачивает то, что заполнил каждый получатель, по одной строке на документ, в формате Excel, CSV или JSON. См. [Экспорт заполненных данных](data-export.md).

## Конфиденциальность

Данные строк хранятся в зашифрованном виде, пока идёт массовая отправка, и удаляются из каждой строки, как только её документ отправлен.

## Через API

Массовая отправка доступна как `POST /api/v1/bulk-sends/preview` (прочитать файл и получить предлагаемое сопоставление, ничего не отправляя) и `POST /api/v1/bulk-sends` (отправить). См. [REST API](api.md#bulk-send).
