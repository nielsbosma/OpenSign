# Участники, роли и порядок подписания

Участник — это любой, кто принимает участие в документе: тот, кто подписывает, согласует или только получает подписанную копию. Участников вы добавляете на странице документа в разделе **Участники**.

## Данные участника

| Поле | |
| --- | --- |
| Имя | Обязательно. Показывается на странице подписания и в доказательствах. |
| Роль | Подписывает, Согласует или Получает копию. См. ниже. |
| Эл. почта | Нужна для доставки по электронной почте и для получения подписанной копии. |
| Мобильный | С кодом страны, например `+46 70 123 45 67`. Нужен для доставки по SMS и кодов из SMS. |
| Компания | Необязательно. Заполняет поля «Компания». |
| Язык | Язык его писем, SMS и страницы подписания. По умолчанию **Как в документе**. См. [Страница подписания](signing-page.md#languages). |
| Отправить ссылку через | Как участник получает ссылку для подписания. См. [Доставка](#delivery). |
| Идентификация для просмотра | Что участник должен сделать, прежде чем сможет открыть документ. См. [Идентификация](identification.md). |
| Идентификация для подписания | Что участник должен сделать, прежде чем сможет подписать. См. [Идентификация](identification.md). |
| Запросить идентификацию по веб-камере | Участник делает своё фото перед подписанием. См. [Фото с веб-камеры](identification.md#webcam-photo). |
| Личный номер | Для идентификации через eID. Если он задан, подписать может только eID этого человека. Хранится в зашифрованном виде и показывается маскированным. |
| Порядок подписания | Когда документ подписывается по порядку, меньшие номера идут первыми. См. [Порядок подписания](#signing-order). |
| Запросить вложения | Файлы, которые участник должен или может загрузить. См. [Вложения подписантов](attachments.md). |

## Роли

| Роль | Что делает участник |
| --- | --- |
| **Подписывает** (подписант) | Читает документ, заполняет свои поля и подписывает нарисованной или введённой подписью. |
| **Согласует** (согласующий) | Читает документ и согласует его. Изображения подписи нет, но согласие попадает в доказательства так же, как подпись. |
| **Получает копию** (наблюдатель) | Не действует. Получает запечатанный PDF, когда документ завершён. У наблюдателя не может быть полей. |

Документ завершён, когда подействовал каждый подписант и согласующий.

## Доставка

| Вариант | |
| --- | --- |
| **Эл. почта** | По умолчанию. OpenSign отправляет по электронной почте приглашение с личной ссылкой и напоминания, если они включены. |
| **SMS** | OpenSign отправляет ссылку текстовым сообщением. Нужен SMS-провайдер в **Настройки → SMS**. |
| **Ссылка (передаёте вы)** | OpenSign ничего не отправляет. При отправке документа он показывает ссылку, которую нужно передать, например в вашем собственном письме или чате, либо показать внутри вашего приложения с помощью [встроенного подписания](embedding.md). |
| **Лично (на вашем устройстве)** | Участник подписывает на вашем компьютере или планшете, начиная со страницы документа. См. [Подписание лично](in-person.md). |
| **Нет** | OpenSign ничего не отправляет и не показывает ссылку. Полезно для наблюдателей, которым нужна только подписанная копия, она приходит на их адрес электронной почты. |

Варианты, которые не настроены в этой установке, показываются, но недоступны для выбора, пока администратор их не настроит.

### Ссылки для подписания

У каждого участника личная ссылка. Она действует только для этого участника и перестаёт работать, когда:

- документ завершён, отклонён, отменён или истёк,
- истекает срок действия самой ссылки: дата окончания документа либо, если её нет, число дней, заданное в **Настройки → Безопасность** (по умолчанию 30), считая с момента первого уведомления участника, или
- участнику выдаётся новая ссылка, которая отзывает старую.

Секретная часть ссылки идёт после `#`, поэтому никогда не попадает в журналы сервера, а страница подписания убирает её из адресной строки. См. [Модель безопасности](security.md#signing-links).

## Порядок подписания

По умолчанию все приглашаются одновременно и могут подписывать в любом порядке. Включите **Подписание по порядку** на карточке **Участники**, чтобы приглашать участников по одному шагу за раз:

- У каждого подписанта и согласующего показан номер его шага. При включении порядка за основу берётся порядок, в котором участники перечислены.
- Стрелками на карточке участника переместите его раньше или позже.
- Чтобы несколько участников подписывали вместе на одном шаге, задайте им одинаковый номер **Порядок подписания** в разделе **Изменить**. Меньшие номера идут первыми.
- Когда все на шаге подействовали, OpenSign приглашает следующий шаг.
- Участник, открывший ссылку до своей очереди, видит «Сначала подписывают другие», и ему приходит письмо, когда подходит его очередь.

Наблюдатели в порядок не входят. В конце они получают запечатанный PDF.

## Отказ

Подписант или согласующий может отказаться, указав необязательную причину. Отказ останавливает документ для всех: он получает статус **Отклонён**, все ссылки перестают работать, отправитель получает уведомление, и срабатывает вебхук `document.declined` с причиной.

## Изменение участников

Участников можно менять, пока документ является черновиком. Удаление участника удаляет и его поля. После отправки документа его участники зафиксированы; чтобы изменить их, отмените документ и создайте новый.
