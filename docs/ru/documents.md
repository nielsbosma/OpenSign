# Документы

Документ в OpenSign — это один или несколько файлов для подписания, участники и поля, которые заполняет каждый из них. Вы готовите черновик, отправляете его, и дальше OpenSign ведёт документ, пока он не будет подписан, отклонён, отменён или не истечёт.

## Жизненный цикл документа

| Статус | Что он значит |
| --- | --- |
| **Черновик** | Вы ещё готовите документ. Файлы, участников и поля можно менять. |
| **Ожидает** | Документ отправлен и ждёт подписей. Его файлы объединены в один PDF, который больше нельзя изменить. |
| **Подписан** | Все, кто должен был действовать, подписали или согласовали. Запечатанный PDF готов. |
| **Отклонён** | Один из участников отказался. Подписание остановлено для всех. |
| **Отменён** | Отправитель (или менеджер) остановил его. |
| **Просрочен** | Срок истёк до того, как все подписали. |

Отправленный документ нельзя редактировать. Чтобы изменить документ в статусе «Ожидает», отмените его и создайте новый черновик.

## Создание документа

Нажмите **Новый документ** на странице **Документы**. Перетащите один или несколько файлов либо начните с [шаблона](templates.md) и укажите название документа.

### Файлы

- Файлы **PDF** принимаются как есть, после очистки (см. ниже).
- Файлы **Word** (`.docx`, `.doc`), **OpenDocument** (`.odt`) и **RTF** конвертируются в PDF с помощью Gotenberg. Для этого в установке должен быть конвертер; без него принимаются только PDF.
- В документе может быть несколько файлов. При отправке они по порядку объединяются в один PDF.
- Максимальный размер загрузки задаёт администратор в **Настройки → Безопасность** (по умолчанию 25 МБ).

Текстовые теги и заполняемые поля формы в файле становятся полями при загрузке. OpenSign сообщает, сколько полей добавлено и какие теги не удалось использовать. См. [Текстовые теги, импорт форм и поиск полей](text-tags.md).

Каждый PDF проверяется по содержимому, а не по имени, и переписывается без JavaScript, действий форм, вложенных файлов, XFA и действий запуска и URI. Если что-то было удалено, OpenSign сообщит, что именно. Исходное активное содержимое никто, включая подписантов, никогда не видит.

### Сведения

| Параметр | |
| --- | --- |
| Название | Показывается в списке документов, в приглашении и на странице подписания. |
| Сообщение участникам | Показывается в приглашении и на странице подписания. |
| Язык для подписантов | Язык писем, SMS и страницы подписания, если у участника нет своего. Если пусто, берётся язык по умолчанию из **Настройки → Организация**. См. [Страница подписания](signing-page.md#languages). |
| Истекает | Дата, после которой документ уже нельзя подписать. Тогда он получает статус **Просрочен**. |
| Напоминать каждые (дней) | Отправляет напоминание участникам, которые ещё не подписали, каждые несколько дней (до 60). 0 отключает напоминания. |
| Ваш номер | Внешний идентификатор, например номер в CRM или номер дела. По нему можно искать в списке документов, он включается в вебхуки и API. |

### Участники

Добавьте всех, кто подписывает, согласует или получает копию. Для каждого участника выберите роль, способ доставки ссылки и способ идентификации. **Подписание по порядку** на той же карточке приглашает их по одному шагу за раз. См. [Участники, роли и порядок подписания](parties.md) и [Идентификация](identification.md).

### Поля

Выберите участника на вкладке **Поля**, затем расставьте поля на страницах. Поля могут также прийти из самого файла: [текстовые теги](text-tags.md#text-tags) вида `{{Sign;type=signature;role=Tenant}}` и поля [заполняемой PDF-формы](text-tags.md#pdf-forms) становятся полями при загрузке, а [Найти поля](text-tags.md#detect-fields) на вкладке **Поля** предлагает поля там, где на странице есть линии и рамки для заполнения. Каждое поле принадлежит одному участнику, который заполняет его при подписании. Выберите поле, чтобы изменить его на панели **Поле**: кто его заполняет, его метку, обязательность и настройки ниже. Щёлкайте по полям с Shift или проведите по странице, чтобы выбрать несколько, затем выровняйте или распределите их на боковой панели. При перетаскивании поля притягиваются друг к другу; удерживайте Alt, чтобы отключить это.

| Поле | |
| --- | --- |
| Подпись | Нарисованная или введённая подпись. |
| Инициалы | Инициалы участника. |
| Текст | Произвольный текст. Может иметь шаблон, длину и значение по умолчанию. |
| Число | Число с наименьшим и наибольшим значением и [форматом](#number-and-date-formats). |
| Раскрывающийся список | Один вариант из списка. |
| Множественный выбор | Любое число вариантов из списка; на странице записываются через запятую. |
| Переключатель | Группа кнопок, из которых участник выбирает одну. См. [Группы переключателей](#radio-groups). |
| Флажок | Может быть обязательным или отмеченным по умолчанию. |
| Телефон | Номер телефона с кодом страны, хранится в виде +46701234567. |
| Выбор даты | Дата, которую участник выбирает в календаре, с самой ранней и самой поздней датой и [форматом](#number-and-date-formats). |
| Изображение | Участник загружает изображение или делает фото. Оно вписывается в рамку с масштабированием. |
| Файл | Участник загружает PDF, JPEG или PNG прямо на странице. Его имя попадает в рамку, а сам файл запечатывается в подписанный PDF, как [вложения](attachments.md). |
| Формула | Число, вычисляемое из других полей, например итог с НДС. См. [Формулы](#formulas). |
| Дата | Заполняется датой подписания в выбранном вами формате. |
| Имя, Эл. почта, Компания | Заполняются из данных участника. |

Выберите **Я, сейчас (заполнено заранее)** на вкладке **Поля**, чтобы поместить значение, которое вы заполняете сами до отправки, например номер договора, сумму или дату. Обязательные поля такого рода нужно заполнить до отправки документа.

У текстовых, числовых, списочных полей, переключателей, флажков, телефонов и дат участника может быть **Значение по умолчанию**, с которого они начинаются. Включите **Только чтение**, и участник увидит его, но не сможет изменить.

#### Проверки и тексты ошибок

Проверки выполняются на странице подписания по мере ввода и ещё раз на сервере при подписании, поэтому значение, нарушающее проверку, никогда не попадёт в запечатанный PDF.

| Проверка | Применяется к | |
| --- | --- | --- |
| Допустимый формат | Текст, инициалы, компания | Готовый шаблон (адрес электронной почты, только цифры, шведский почтовый индекс, личный номер или номер организации) или собственное регулярное выражение. Значение должно соответствовать ему целиком. |
| Мин. длина, Макс. длина | Текст, инициалы, компания | В символах. |
| Наименьшее, Наибольшее | Число | Включительно. |
| Не раньше, Не позже | Выбор даты | Включительно. |
| Обязательно | Каждое поле, которое заполняет участник | |

**Текст ошибки** заменяет встроенную ошибку вашей собственной для любой проверки этого поля, например *Напишите номер заказа как AB1234*. Без него участник видит встроенную ошибку на своём языке.

Шаблоны используют распространённый синтаксис регулярных выражений: классы вроде `[0-9]` и `\d`, повторения вроде `{3}`, `+` и `?`, альтернативы через `|` и группы. Опережающие проверки и обратные ссылки не поддерживаются — это позволяет каждой проверке выполняться быстро.

#### Форматы чисел и дат

Формат определяет, как значение записывается на странице; хранится оно в простом виде (`1234.5`, `2026-12-31`), поэтому экспорт и API всегда получают одну и ту же форму.

Запишите формат числа так, как в нём выглядело бы 1234. `1,234.00` даёт запятую между тысячами и два знака после точки, `1 234,00 kr` — пробел, десятичную запятую и валюту после числа, а `$1234` — без десятичных знаков и со знаком доллара. Значения округляются по правилу «от половины вверх» до числа знаков формата. Участники могут вводить числа любым из способов, например `1 234,5` или `1,234.50`.

Даты можно записывать как YYYY-MM-DD, DD/MM/YYYY, MM/DD/YYYY, DD.MM.YYYY или D MMM YYYY (31 Dec 2026). Те же форматы действуют для даты подписания.

#### Группы переключателей

Размещение **Переключателя** добавляет одну кнопку. Выберите её и нажмите **Добавить кнопку в группу** для каждого следующего варианта, затем перетащите кнопки на нужные места. Каждая кнопка содержит один вариант; группа имеет общую метку и общий признак обязательности ответа. Участник может выбрать одну кнопку группы.

#### Условные поля

В разделе **Показывать, Только Когда** на панели «Поле» добавьте условия для других полей. Поле показывается, только пока выполнены все условия, например *Номер организации* только когда *Тип* равен *Компания*, или поле *Причина* только когда отмечен флажок *Другое*. Поля с условиями отображаются в редакторе пунктирной рамкой.

| Правило | |
| --- | --- |
| Равно, Не Равно | Сравнивает с вариантом, числом или текстом. Текст сравнивается без учёта регистра, а числа — по значению, поэтому 10 и 10.0 одинаковы. |
| Заполнено, Пусто | Для флажка: Отмечен, Не Отмечен. |
| Содержит | В списке множественного выбора отмечен вариант, или текст содержит слова. |
| Больше, Меньше | Числа и даты (Позже, Раньше). |

Скрытое поле никогда не бывает обязательным, остаётся пустым при подписании участником и не записывается в подписанный PDF. Поле, зависящее от скрытого, видит его как пустое, поэтому скрытие распространяется по цепочке.

Условия ссылаются на поля по их метке, поэтому у поля, на которое вы смотрите, должна быть метка, и только у одного поля она может быть такой. Переименование поля в редакторе обновляет условия и формулы, которые его используют. Поле участника может смотреть на его собственные поля, на значения, которые вы заполнили заранее, и на поля участников, которые подписывают раньше, если включено **Подписание по порядку**. Сервер проверяет условия ещё раз при подписании, поэтому участник не может пропустить поле, изменив страницу.

#### Формулы

Поле **Формула** вычисляет число из других полей, пока участник заполняет документ. Участник видит результат, но не может его изменить, а сервер при подписании вычисляет его заново из отправленных значений, поэтому сохранённому результату можно доверять. Задайте [формат числа](#number-and-date-formats), чтобы округлить и записать результат, например `1 234,00 kr`.

Записывайте метки других полей в фигурных скобках и используйте `+ - * /` (или `× ÷`), круглые скобки и следующие функции:

| Функция | |
| --- | --- |
| `round(x, 2)` | Округляет по правилу «от половины вверх» до 0–6 знаков после запятой; без второго значения — до целого. |
| `floor(x)`, `ceil(x)`, `abs(x)` | Вниз, вверх или без знака. |
| `min(a, b, …)`, `max(a, b, …)`, `sum(a, b, …)` | |
| `if(condition, then, else)` | Условия сравниваются через `=`, `!=`, `<`, `<=`, `>` и `>=` и объединяются через `and(…)`, `or(…)` и `not(…)`. |
| `contains(list, "text")` | Отмечен ли вариант в списке множественного выбора или содержит ли текст слова. |

Примеры:

- НДС с цены: `{Price} * 0.25`
- Итог с НДС: `round({Hours} * {Rate} * 1.25, 2)`
- Скидка при сумме выше порога: `if({Amount} >= 10000, {Amount} * 0.05, 0)`
- Цена по тарифу: `if({Plan} = "Pro", 99, 49) * {Seats}`

Пустое поле считается за 0, отмеченный флажок — за 1. Формула, которая делит на ноль или использует текст, не являющийся числом, остаётся пустой. Формула, которую заполняете вы сами, может использовать только ваши заранее заполненные поля и вычисляется при сохранении; формула участника может использовать те же поля, что и [условие](#conditional-fields).

Поля хранятся как доли страницы, поэтому остаются на месте при любом размере страницы.

## Перед отправкой

Панель **Проверка** проверяет настройку документа по ходу работы и перечисляет всё, что помешает подписанию или ослабит результат:

- Ошибки, блокирующие отправку: нет файла, нет подписанта или согласующего, участник получает ссылку по электронной почте или в SMS, но у него нет адреса электронной почты или номера телефона, участник должен подтвердиться кодом из SMS, но у него нет номера телефона, у наблюдателя есть поля для заполнения, обязательное поле отправителя не заполнено.
- Предупреждения, на которые стоит взглянуть: у подписанта нет поля подписи (тогда его подпись появится только на странице доказательств), у участника с eID нет личного номера (поэтому подписать мог бы любой, у кого есть ссылка и eID), у участника нет ни адреса электронной почты, ни телефона (поэтому он не получит подписанную копию).

Если администратор настроил ИИ, на той же панели можно также попросить ИИ прочитать документ. См. [ИИ-ассистент и проверка](ai.md#document-review).

## Предпросмотр

**Предпросмотр** рядом с **Отправить на подпись** показывает страницу подписания так, как её увидит выбранный участник: с его полями, языком и шагами идентификации. См. [Страница подписания](signing-page.md#previewing-as-a-party).

## Проверка ИИ подписантами

По умолчанию подписанты могут дать своему ИИ-ассистенту копию документа только для чтения, чтобы он объяснил документ до подписания. Чтобы запретить это, отключите **Разрешить подписантам делиться со своим ИИ** в разделе **Проверка ИИ подписантами**. См. [Страница подписания](signing-page.md#review-with-your-ai).

## Отправка

Нажмите **Отправить на подпись**. OpenSign объединит файлы в один PDF, заблокирует его и уведомит первых участников. Для участников со способом доставки **Ссылка** OpenSign покажет **Передать ссылки для подписания** с каждой ссылкой для копирования. Новую ссылку позже можно получить на карточке участника, а **Новая ссылка** сначала отзывает старую.

## Пока документ ожидает

На странице документа вы можете:

- **Напомнить** всем, чья очередь подписывать и кто ещё не подписал.
- Получить или заменить ссылку для подписания участника.
- Запустить **Подписать лично** для участника, который подписывает на вашем устройстве. См. [Подписание лично](in-person.md).
- **Отмена**: отменить документ, указав необязательную причину. Все ссылки для подписания перестают работать, а участники, которых уведомляли, получают сообщение.
- Просмотреть **Активность**: каждый шаг журнала аудита документа, например кто открыл, идентифицировал, подписал или скачал его.

## Когда всё готово

Когда последний участник подписал, OpenSign запечатывает документ в фоновом режиме, обычно за несколько секунд. После этого на странице документа доступны запечатанный PDF и оригинал в том виде, в каком он был отправлен. Участники с адресом электронной почты тоже получают запечатанный PDF. См. [Запечатанные PDF и доказательства](sealed-pdfs.md).

Каждое скачивание записывается в журнал аудита.

Чтобы получить заполненное участниками в виде данных, выберите **Экспорт данных** в меню **⋯**. См. [Экспорт заполненных данных](data-export.md).

## Доступ для коллег

Документы принадлежат тому, кто их создал. Чтобы коллега мог увидеть документ, откройте ему доступ и при желании разрешите изменять его. Менеджеры, аудиторы и администраторы видят все документы без предоставления доступа. См. [Пользователи и роли](users-and-roles.md).

## Удаление

Документ, который не находится в статусе «Ожидает», можно удалить вместе с файлами. Ожидающий документ сначала отмените. Подписанные документы могут удалять только те, кто управляет всеми документами, а документ под юридическим удержанием не может удалить никто. Удаление записывается в журнал аудита. Документы также могут удаляться автоматически по правилам хранения. См. [Хранение и юридическое удержание](retention.md).

## Поиск документов

Страница **Документы** показывает документы, которые вы можете видеть, сначала новые, со вкладками по статусам. Ищите по названию или по вашему номеру.

Раскладывайте документы по папкам в столбце папок рядом со списком и архивируйте завершённые, чтобы они исчезли со вкладок статусов. Они перечислены на вкладке **В архиве**. См. [Папки и архив](folders.md).
