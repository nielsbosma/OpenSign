# الأطراف والأدوار وترتيب التوقيع

الطرف هو كل من يشارك في مستند: من يوقّع أو يوافق أو يتلقى النسخة الموقّعة فقط. تضيف الأطراف في صفحة المستند تحت **الأطراف**.

## بيانات الطرف

| الحقل | |
| --- | --- |
| الاسم | مطلوب. يظهر على صفحة التوقيع وفي الأدلة. |
| الدور | يوقّع أو يوافق أو يتلقى نسخة. انظر أدناه. |
| البريد الإلكتروني | مطلوب للإرسال بالبريد الإلكتروني ولتلقي النسخة الموقّعة. |
| الجوال | مع رمز البلد، مثل `+46 70 123 45 67`. مطلوب للإرسال بالرسائل النصية ولرموزها. |
| الشركة | اختياري. يملأ حقول الشركة. |
| اللغة | لغة رسائله البريدية ورسائله النصية وصفحة التوقيع. **مثل المستند** افتراضيًا. راجع [صفحة التوقيع](signing-page.md#languages). |
| إرسال الرابط عبر | كيف يحصل الطرف على رابط توقيعه. راجع [طريقة الإرسال](#delivery). |
| إثبات الهوية للعرض | ما يجب أن يفعله الطرف قبل أن يتمكن من فتح المستند. راجع [إثبات الهوية](identification.md). |
| إثبات الهوية للتوقيع | ما يجب أن يفعله الطرف قبل أن يتمكن من التوقيع. راجع [إثبات الهوية](identification.md). |
| طلب التحقق عبر كاميرا الويب | يلتقط الطرف صورة لنفسه قبل التوقيع. راجع [صورة كاميرا الويب](identification.md#webcam-photo). |
| الرقم الشخصي | للتحقق بالهوية الإلكترونية. عند تعيينه، لا يستطيع التوقيع إلا الهوية الإلكترونية لذلك الشخص. يُخزَّن مشفّرًا ويُعرض مخفيًا جزئيًا. |
| ترتيب التوقيع | عندما يوقَّع المستند بالترتيب، تأتي الأرقام الأدنى أولًا. راجع [ترتيب التوقيع](#signing-order). |
| طلب مرفقات | ملفات يجب على الطرف رفعها أو يجوز له ذلك. راجع [مرفقات الموقّعين](attachments.md). |

## الأدوار

| الدور | ما يفعله الطرف |
| --- | --- |
| **يوقّع** (موقّع) | يقرأ المستند، ويملأ حقوله، ويوقّع بتوقيع مرسوم أو مكتوب. |
| **يوافق** (موافق) | يقرأ المستند ويوافق عليه. بدون صورة توقيع، لكن الموافقة تظهر في الأدلة مثل التوقيع. |
| **يتلقى نسخة** (مشاهد) | لا يتصرف. يحصل على ملف PDF المختوم عند اكتمال المستند. ولا يمكن أن تكون للمشاهد حقول. |

يكتمل المستند عندما يتصرف كل موقّع وموافق.

## طريقة الإرسال

| الخيار | |
| --- | --- |
| **البريد الإلكتروني** | الافتراضي. يرسل OpenSign دعوة بالبريد الإلكتروني فيها الرابط الشخصي، ومعها التذكيرات إن كانت مفعّلة. |
| **الرسائل النصية** | يرسل OpenSign الرابط في رسالة نصية. يحتاج إلى مزوّد رسائل نصية في **الإعدادات ← الرسائل النصية**. |
| **رابط (تسلّمه أنت)** | لا يرسل OpenSign شيئًا. وعندما ترسل المستند يعرض لك الرابط لتمريره، مثلًا في بريدك أو محادثتك، أو لعرضه داخل تطبيقك بـ[التوقيع المضمّن](embedding.md). |
| **حضوريًا (على جهازك)** | يوقّع الطرف على حاسوبك أو جهازك اللوحي، ويبدأ ذلك من صفحة المستند. راجع [التوقيع الحضوري](in-person.md). |
| **لا شيء** | لا يرسل OpenSign شيئًا ولا يعرض رابطًا. مفيد للمشاهدين الذين يحتاجون النسخة الموقّعة فقط، وتذهب إلى بريدهم الإلكتروني. |

الخيارات غير المعدّة في هذا التثبيت تظهر لكن لا يمكن اختيارها إلى أن يعدّها المسؤول.

### روابط التوقيع

لكل طرف رابط شخصي. لا يصلح إلا لذلك الطرف، ويتوقف عن العمل عندما:

- يكتمل المستند أو يُرفض أو يُلغى أو ينتهي،
- ينتهي عمر الرابط نفسه: تاريخ انتهاء المستند، أو إن لم يوجد فعدد الأيام المحدد في **الإعدادات ← الأمان** (30 افتراضيًا)، محسوبًا من وقت إخطار الطرف أول مرة، أو
- يصدر رابط جديد للطرف، فيُلغى القديم.

الجزء السري من الرابط يأتي بعد الرمز `#`، فلا يصل أبدًا إلى سجلات الخادم، وتزيله صفحة التوقيع من شريط العنوان. راجع [نموذج الأمان](security.md#signing-links).

## ترتيب التوقيع

افتراضيًا يُدعى الجميع دفعة واحدة ويمكنهم التوقيع بأي ترتيب. فعّل **التوقيع بالترتيب** في بطاقة **الأطراف** لدعوة الأطراف خطوة خطوة:

- يعرض كل موقّع وموافق رقم خطوته. وتفعيل الترتيب يبدأ من الترتيب الذي سُردت به الأطراف.
- استخدم الأسهم في بطاقة الطرف لتقديمه أو تأخيره.
- لتتيح لعدة أطراف التوقيع معًا في الخطوة نفسها، أعطهم رقم **ترتيب التوقيع** نفسه تحت **تعديل**. الأرقام الأدنى أولًا.
- عندما يتصرف كل من في الخطوة، يدعو OpenSign الخطوة التالية.
- الطرف الذي يفتح رابطه قبل أن يحين دوره يرى "يوقّع آخرون قبلك" ويصله بريد إلكتروني عندما يحين دوره.

المشاهدون ليسوا جزءًا من الترتيب. يحصلون على ملف PDF المختوم في النهاية.

## الرفض

يستطيع الموقّع أو الموافق الرفض، مع ذكر سبب اختياري. الرفض يوقف المستند للجميع: يصبح **مرفوض**، وتتوقف كل الروابط عن العمل، ويُبلَّغ المرسل، ويُطلق Webhook من النوع `document.declined` مع السبب.

## تغيير الأطراف

يمكن تغيير الأطراف ما دام المستند مسودة. وإزالة طرف تزيل حقوله أيضًا. وبعد إرسال المستند تصبح أطرافه ثابتة؛ ولتغييرها، ألغِ المستند وابدأ مستندًا جديدًا.
