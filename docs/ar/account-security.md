# تسجيل الدخول ومفاتيح المرور والمصادقة الثنائية

يحمي حسابك كلمة مرور، ويُستحسن عامل ثانٍ: تطبيق مصادقة أو مفتاح مرور. تدير الاثنين تحت **الإعدادات ← الحساب**.

## كلمات المرور

- 12 حرفًا على الأقل. العبارات الطويلة مرحّب بها.
- تُجزَّأ كلمات المرور بـ Argon2id. لا يستطيع أحد قراءتها، ولا حتى المسؤولون.
- بعد محاولات تسجيل دخول فاشلة متكررة من عنوان واحد، يُقفل ذلك العنوان لهذا الحساب مدة، تبدأ بدقيقة وتزداد حتى ساعة. ويوم بلا إخفاقات ينسيها. ولا يقفل الحساب للجميع إلا إخفاقات من عدة عناوين في آن واحد، ويسجّل مفتاح المرور الدخول حتى حينها. وتُسجَّل كل محاولة.
- يطلب **تغيير كلمة المرور** كلمة المرور الحالية ويُخرجك من جلساتك الأخرى.
- ترسل **هل نسيت كلمة المرور؟** في صفحة تسجيل الدخول رابط إعادة تعيين بالبريد الإلكتروني يعمل ساعة. وإعادة التعيين تُخرج كل الجلسات وتلغي مفاتيح API الخاصة بك، ويصلك بريد إلكتروني إن أُلغي أي منها. وإذا كان لحسابك مفتاح مرور، فلا تزال تحتاج إليه لتسجيل الدخول بعد ذلك.

## المصادقة الثنائية بتطبيق مصادقة

1. تحت **المصادقة الثنائية**، ابدأ الإعداد وامسح رمز QR بتطبيق مصادقة، مثل 1Password أو Google Authenticator أو Microsoft Authenticator.
2. أدخل الرمز المكوّن من 6 أرقام للتأكيد.
3. احفظ **رموز الاسترداد**. يُسجّل كل رمز دخولك مرة واحدة إذا فقدت هاتفك. وتُعرض هذه المرة فقط.

ومن حينها يطلب تسجيل الدخول رمزًا بعد كلمة المرور. وإذا فقدت هاتفك ورموز الاسترداد معًا، يستطيع المسؤول إعادة تعيين مصادقتك الثنائية (راجع [المستخدمون والأدوار](users-and-roles.md)).

## مفاتيح المرور

يتيح لك مفتاح المرور تسجيل الدخول بـ Face ID أو Touch ID أو Windows Hello أو هاتفك أو مفتاح أمان، دون كتابة كلمة مرور.

1. تحت **مفاتيح المرور**، اختر **إضافة مفتاح مرور**، وأعطه اسمًا (مثل "MacBook") وأكّد كلمة مرورك.
2. اتبع موجّه المتصفح.

ثم اختر **تسجيل الدخول بمفتاح مرور** في صفحة تسجيل الدخول. يتحقق مفتاح المرور منك دائمًا على الجهاز (ببصمة أو وجه أو رقم PIN)، فيُحتسب مصادقة ثنائية بنفسه ولا يُطلب أي رمز. ويمكنك إضافة عدة مفاتيح وإزالة أي منها.

وما إن يكون لحسابك مفتاح مرور ولا يكون له تطبيق مصادقة، لا تكفي كلمة المرور وحدها لتسجيل دخولك: بعد كلمة المرور يُطلب منك مفتاح المرور أيضًا. وإذا فقدت كل مفاتيح المرور، يستطيع المسؤول إعادة تعيين مصادقتك الثنائية، مما يزيلها.

## تأكيد أنك أنت

إنشاء مفتاح API أو ربط تطبيق يمنح وصولًا دائمًا، لذلك يطلب OpenSign كلمة مرورك أو مفتاح مرور أولًا، ما لم تكن قد سجّلت الدخول أو أكّدت خلال آخر عشر دقائق.

## فرض المصادقة الثنائية على الجميع

يستطيع المسؤول تفعيل **فرض المصادقة الثنائية على الجميع** في **الإعدادات ← الأمان**. عندئذ يُطلب من كل من ليس لديه تطبيق مصادقة أو مفتاح مرور أن يُعدّ واحدًا قبل أن يفعل أي شيء آخر. وتُرفض عملاء MCP المسجَّلون بحساب كهذا إلى أن يفعل. ونوصي بتفعيل هذا.

## تسجيل الدخول الموحد

إذا كانت مؤسستك تستخدم [تسجيل الدخول الموحد](single-sign-on.md)، فاختر زره في صفحة تسجيل الدخول. يتولى مزوّد الهوية لديك عندئذ كلمة مرورك وعاملك الثاني وبريدك الإلكتروني، ولا يكون في **الإعدادات ← الحساب** مفاتيح مرور ولا تطبيق مصادقة ولا كلمة مرور لك. ولا تتوفر مفاتيح API ولا عملاء MCP لهذه الحسابات.

## اللغة

تحت **الإعدادات ← الحساب والأمان**، اختر اللغة التي يُعرض بها OpenSign لك: الإنجليزية أو الصينية (المبسطة) أو الهندية أو الإسبانية أو الفرنسية أو العربية أو البنغالية أو البرتغالية أو الروسية أو الأردية أو السويدية. قبل تسجيل الدخول يتبع التطبيق متصفحك، ولصفحة تسجيل الدخول منتقٍ للغة. ولا يغيّر هذا ما يراه الموقّعون؛ فهم يحصلون على اللغة المحددة في مستندهم أو طرفهم. وبعض الرسائل من الخادم ما زال بالإنجليزية.

## التوقيع المحفوظ

تحت **الإعدادات ← الحساب والأمان ← توقيعي**، ارسم توقيعك أو اكتبه مرة واحدة، وأضف أحرفك الأولى إن شئت. وعندما توقّع مستندًا بنفسك، تعرضه صفحة التوقيع في تبويب **محفوظ**. لا يُطبَّق من تلقاء نفسه أبدًا: فأنت ما زلت تختار التوقيع، ويمكنك رسم توقيع جديد أو كتابته بدلًا منه.

لا يُعرض إلا عندما يعود رابط التوقيع إليك: عندما [توقّع مستندًا بنفسك](in-person.md#signing-a-document-yourself)، أو تفتح رابطًا أُرسل إلى بريدك الإلكتروني وأنت مسجّل الدخول. ومن تسلّمه جهازك للتوقيع الحضوري لا يراه أبدًا. ويُخزَّن الرسم مشفّرًا كأي ملف آخر، و**إزالة** تحذفه. ويُسجَّل حفظه وإزالته في سجل التدقيق.

الموقّعون الخارجيون ليس لهم حساب، فيمكنهم بدلًا من ذلك تحديد **تذكّر توقيعي في هذا المتصفح**. وهذا يبقيه في متصفحهم فقط، ويُعرض في المرة التالية لطرف يحمل الاسم نفسه؛ ولا يُخزَّن شيء عنهم على الخادم بين المستندات. راجع [صفحة التوقيع](signing-page.md#signing).

## الجلسات

الجلسات ملفات تعريف ارتباط في المتصفح لا تستطيع النصوص البرمجية قراءتها، ومرتبطة بتثبيتك، وتُخزَّن على الخادم تجزئة بمفتاح فقط. في **الإعدادات ← الأمان** يضبط المسؤول:

| الإعداد | الافتراضي | |
| --- | --- | --- |
| مدة الجلسة (ساعات) | 12 | أقصى مدة يدوم فيها تسجيل الدخول. |
| تسجيل الخروج بعد الخمول (دقائق) | 60 | كم تبقى الجلسة دون استخدام. |

ينهي **تسجيل الخروج** في قائمة المستخدم الجلسة في هذا المتصفح.

## التطبيقات المتصلة عبر MCP

تحت **تطبيقات الذكاء الاصطناعي (MCP)** ترى عنوان خادم MCP لتثبيتك والعملاء الذين ربطتهم، مثل Claude. افصل أيًا منهم في أي وقت. راجع [MCP وClaude](mcp.md).

## مفاتيح API

تُدار مفاتيح API تحت **الإعدادات ← مفاتيح API**. راجع [REST API](api.md#api-keys).
