# البدء السريع

تأخذك هذه الصفحة من الصفر إلى مستند موقّع على جهازك. وللتثبيت في بيئة إنتاج اقرأ [النشر](deployment.md) بعد ذلك.

## 1. تشغيل OpenSign محليًا

تحتاج إلى Docker ونسخة من المستودع.

```sh
git clone https://github.com/nielsbosma/OpenSign.git
cd OpenSign
docker compose up -d --wait postgres s3 mailpit converter
docker compose run --rm s3-init
docker compose --profile prod up -d --build
```

يشغّل الأمران الأولان Postgres ومخزنًا متوافقًا مع S3 وGotenberg لملفات Word وMailpit، وينشئان الحاويات. أما الأمر الأخير فيبني صورة الإنتاج ويشغّلها.

- OpenSign: http://localhost:8090
- Mailpit، صندوق بريد محلي للتطوير: http://localhost:8026

ترسل صورة الإنتاج بريدًا حقيقيًا، لذا تحتاج إلى حساب بريد حقيقي (الخطوة 3). ولتجربة OpenSign بدون حساب بريد، شغّله في وضع التطوير، حيث يصل كل بريد إلى Mailpit:

```sh
pnpm install
pnpm infra:up
cp .env.example .env
pnpm dev            # web app on http://localhost:5173
```

## 2. إنشاء أول مسؤول

يطبع التثبيت الجديد **رمز إعداد** في سجله، حتى لا يستطيع أحد غيرك الاستيلاء عليه قبلك.

```sh
docker compose logs app | grep "setup code"
```

في وضع التطوير يظهر الرمز في الطرفية التي يعمل فيها `pnpm dev`.

افتح OpenSign، وأدخل رمز الإعداد واسمك ومؤسستك وبريدك الإلكتروني وكلمة مرور. راجع [الإعداد الأول والبريد الإلكتروني](setup.md) لمعرفة ما تفعله كل خطوة.

## 3. ربط البريد الإلكتروني

يرسل OpenSign الدعوات والرموز والمستندات الموقّعة بالبريد الإلكتروني، ولذلك يطلب مزوّد بريد قبل أن يتمكن أي شخص من الإرسال. أدخل مفتاح Resend API وعنوان مرسل على نطاق تحققت منه في Resend. يرسل لك OpenSign رسالة اختبار ولا يتابع إلا بعد وصولها.

في وضع التطوير يمكنك ترك المفتاح فارغًا: تذهب رسالة الاختبار وكل ما بعدها إلى Mailpit.

## 4. إرسال مستند

1. انتقل إلى **المستندات** واختر **مستند جديد**.
2. أفلت ملف PDF أو Word، وأعطه عنوانًا، ثم أنشئه.
3. أضف نفسك ضمن **الأطراف** موقّعًا ببريدك الإلكتروني.
4. اختر الطرف في شريط أدوات الحقول وضع حقل **التوقيع** على الصفحة.
5. اختر **إرسال للتوقيع**.

افتح الدعوة، واتبع الرابط، وارسم توقيعًا أو اكتبه ثم وقّع. بعد ثوانٍ يصبح المستند **موقّع**، ويمكنك تنزيل ملف PDF المختوم من صفحة المستند.

## 5. التحقق من النتيجة

افتح **التحقق من مستند** في الشريط الجانبي (أو انتقل إلى `/verify`) وأفلت ملف PDF المختوم. يفحص OpenSign الختم والأختام الزمنية ويؤكد أنه ختم هذا الملف بالذات. كما يعرض قارئ PDF يدعم التواقيع، مثل Adobe Acrobat، الختم أيضًا.
