# وسوم النص واستيراد النماذج واكتشاف الحقول

لا تحتاج إلى سحب كل حقل إلى الصفحة. يستطيع OpenSign قراءة الحقول من الملف نفسه بثلاث طرق:

- **وسوم النص** التي تكتبها داخل ملف Word أو PDF، مثل `{{Tenant Sign;role=Tenant;type=signature}}`.
- **نماذج PDF**: تتحول حقول ملف PDF القابل للتعبئة إلى حقول OpenSign، مع القيم التي عُبّئت بها.
- **اكتشاف الحقول** في المحرر يقترح حقولًا حيث توجد في الصفحة خطوط أو شرطات سفلية أو مربعات للتعبئة.

الحقول المنشأة بأي من هذه الطرق حقول عادية. يمكنك نقلها وتغيير حجمها وتعديلها أو إزالتها قبل الإرسال.

## وسوم النص

اكتب وسمًا في المكان الذي ينبغي أن يوضع فيه حقل، داخل نص المستند. عند رفع الملف يحوّل OpenSign كل وسم إلى حقل في مكان الوسم ويزيل نص الوسم من الصفحة، فلا يراه الموقّعون. ويبقى باقي السطر في مكانه تمامًا.

الصيغة هي نفسها في DocuSeal، لذلك تعمل النماذج المصنوعة لـ DocuSeal دون تغيير:

```
{{Field Name;role=Tenant;type=signature;required=false}}
```

الجزء الأول هو اسم الحقل، ويظهر كتسمية له. بعده تأتي سمات بالشكل `key=value` مفصولة بفواصل منقوطة. يمكن للوسم أن يحذف الاسم ويبدأ بسمة، مثل `{{type=checkbox}}`.

| السمة | |
| --- | --- |
| `type` | نوع الحقل، انظر أدناه. يكون `text` عند عدم كتابتها. |
| `role` | الطرف الذي يملؤه، بالاسم، مثل `Tenant` أو `Landlord`. الدور الذي لا يوجد في المستند بعد يُضاف كطرف جديد؛ عبّئ بياناته قبل الإرسال. وبدون دور، يذهب الحقل إلى أول طرف يوقّع. |
| `required` | القيمة `false` تجعل الحقل اختياريًا. الحقول مطلوبة افتراضيًا، أما مربعات الاختيار فلا. |
| `readonly` | القيمة `true` تعرض القيمة الافتراضية للطرف دون أن تتيح له تغييرها. |
| `default` | قيمة يبدأ منها الطرف. |
| `title` | تسمية غير الاسم. |
| `options` | خيارات حقل `select` أو `multiple`، مفصولة بفواصل (أو بالرمز `|`). |
| `option` | الخيار الواحد الذي يمثله زر `radio`. وسوم الاختيار التي لها الاسم نفسه تكوّن مجموعة واحدة. |
| `format` | تنسيق تاريخ مثل `DD/MM/YYYY` أو `MM/DD/YYYY`، أو تنسيق رقم: `usd` أو `eur` أو `gbp` أو `sek`، أو كما سيبدو 1234، مثل `1 234,00 kr`. راجع [تنسيقات الأرقام والتواريخ](documents.md#number-and-date-formats). |
| `min`, `max` | أصغر رقم وأكبره، أو أبكر تاريخ وأحدثه بالصيغة YYYY-MM-DD. |
| `width`, `height` | حجم الحقل بالنقاط (1/72 بوصة). وبدونهما يكون الحقل بعرض الوسم وارتفاع نصه، وتحصل التواقيع والأحرف الأولى والصور على حد أدنى معقول، وتنمو إلى الأعلى من الخط. |

| النوع | الحقل |
| --- | --- |
| `text` | نص |
| `signature` | التوقيع |
| `initials` | الأحرف الأولى |
| `date` | منتقي التاريخ |
| `datenow` | تاريخ التوقيع، يُملأ تلقائيًا |
| `number` | رقم |
| `select` | قائمة منسدلة |
| `multiple` | اختيار متعدد |
| `radio` | زر اختيار واحد |
| `checkbox` | مربع اختيار |
| `phone` | الهاتف |
| `image`, `file` | رفع صورة أو ملف |
| `name`, `email`, `company` | تُملأ من بيانات الطرف (في OpenSign فقط) |

أمثلة:

```
{{Client Name;role=Client}}
{{Client Sign;type=signature;role=Client}}
{{Start Date;type=date;format=DD/MM/YYYY;role=Client}}
{{Region;type=select;options=North,South,East,West}}
{{Plan;type=radio;option=Basic}} Basic   {{Plan;type=radio;option=Plus}} Plus
{{type=checkbox;role=Client}} I accept the terms
{{Amount;type=number;format=sek;min=0}}
```

الوسم الذي لا يمكن استخدامه يبقى على الصفحة كنص، ويخبرك OpenSign بالسبب عند الرفع: نوع لا يوجد في OpenSign (مثل `payment` أو `stamp` أو `verification` في DocuSeal)، أو سمة بلا قيمة، أو قيمة لا يقبلها الحقل، أو وسم مقطوع على سطرين. أما السمات التي لا يستفيد منها OpenSign، مثل الخطوط والألوان، فتُتجاهل.

### كتابة الوسوم في Word

اكتب الوسوم كنص عادي. أبقِ كل وسم في سطر واحد: قصّر الاسم أو صغّر الخط إذا لفّه Word. يحدد حجم خط الوسم ارتفاع الحقل، فوسم بخط 8 نقاط يعطي حقلًا قصيرًا. تعمل وسوم النص في ملفات Word وOpenDocument وRTF في التثبيتات التي فيها محوّل مستندات، وفي أي ملف PDF يمكن قراءة نصه. أما الصفحات الممسوحة ضوئيًا فلا نص فيها، فلا وسوم فيها.

### إيقاف الوسوم

تُقرأ الوسوم عند كل رفع. ولرفع ملف يحتوي نصه مصادفةً على `{{` و`}}`، أوقفها عبر API بالمعامل `textTags=false`. أما واجهتا [Scrive](scrive.md) و[DocuSign](docusign.md) فلا تقرآن الوسوم أبدًا.

## نماذج PDF

يتحول نموذج PDF القابل للتعبئة (AcroForm) إلى حقول عند رفعه: تصبح مربعات النص حقول نص، ومربعات الاختيار مربعات اختيار، وأزرار الاختيار مجموعة أزرار اختيار، والقوائم قوائم منسدلة أو اختيارًا متعددًا، ومربعات التوقيع حقول توقيع. وتصبح القيم التي عُبّئ بها النموذج قيمًا افتراضية، وتبقى الحقول المعلَّمة كمطلوبة في النموذج مطلوبة.

يذهب حقل النموذج الذي يبدأ اسمه باسم طرف إلى ذلك الطرف: `Tenant.Name` و`Tenant name` يذهبان إلى Tenant. أما غيرهما فيذهب إلى أول طرف يوقّع. ويُزال النموذج نفسه من الملف مع ذلك، كما في كل رفع، فلا تبقى إلا حقول OpenSign. ولا تُقرأ نماذج XFA.

## اكتشاف الحقول

يفحص **اكتشاف الحقول** في شريط أدوات الحقول الصفحات بحثًا عن أماكن تحتاج إلى حقل:

- خطوط وسلاسل شرطات سفلية للكتابة عليها، مع التسمية بجانبها أو تحتها،
- مربعات فارغة للتحديد، مع النص المجاور لها كتسمية.

تحدد التسمية نوع الحقل: Signature أو Underskrift أو Firma تصبح حقل توقيع، وName أو Namnförtydligande اسمًا، وDate أو Datum تاريخ التوقيع، وDate of birth منتقي تاريخ، وEmail وPhone وCompany حقولها الخاصة، وأي شيء آخر نصًا.

تُرسم الاقتراحات بحدود متقطعة ولا يُحفظ شيء قبل أن تقبلها. انقر على اقتراح لإضافته، أو **قبول الكل**. تذهب إلى الطرف المحدد في شريط الأدوات؛ أما التواقيع والأحرف الأولى فتذهب إلى موقّع. مرّر المؤشر فوق اقتراح وانقر على علامة الإغلاق لتجاهله. والأماكن التي فيها حقل بالفعل لا تُقترح مرة أخرى.

### بالذكاء الاصطناعي

عندما يكون [مزوّد ذكاء اصطناعي](ai.md) معدًّا ويكون **السماح بإرسال نص المستندات للمراجعة** مفعّلًا، يعرض اكتشاف الحقول أيضًا **بالذكاء الاصطناعي أيضًا**. عندها يرسل OpenSign إلى النموذج نص كل صفحة مع مواضعه والأماكن التي وجدها بالفعل، ويضيف اقتراحات النموذج مميزة بشرارة. لا يرسل صورًا، ولا أكثر من 30 صفحة وحوالي 40,000 حرف، وتُحتسب المكالمة على ميزانية الذكاء الاصطناعي. ويُكتب كل اكتشاف بالذكاء الاصطناعي في [سجل التدقيق](audit-log.md).

## عبر API

يقرأ `POST /api/v1/documents/{id}/files` و`documents.upload` وسوم النص وحقول النماذج ما لم تكن `textTags` أو `formFields` تساوي `false`. وتخبرك `fields` في الاستجابة بعدد الحقول المنشأة من كل مصدر، وبالأطراف المضافة، وبالوسوم التي تعذّر استخدامها.

يعيد `documents.detect_fields` اقتراحات لمسودة دون حفظ أي شيء. مرّر `ai: true` لتسأل نموذج الذكاء الاصطناعي أيضًا. ضع ما تريده منها بـ `documents.set_fields`. راجع [API](api.md).
