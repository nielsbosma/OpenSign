# فوری آغاز

یہ صفحہ آپ کو بالکل شروع سے اپنی مشین پر دستخط شدہ دستاویز تک لے جاتا ہے۔ پروڈکشن انسٹال کے لیے اگلا [ڈیپلائمنٹ](deployment.md) پڑھیں۔

## 1. OpenSign مقامی طور پر چلائیں

آپ کو Docker اور ریپوزٹری کی ایک کاپی چاہیے۔

```sh
git clone https://github.com/nielsbosma/OpenSign.git
cd OpenSign
docker compose up -d --wait postgres s3 mailpit converter
docker compose run --rm s3-init
docker compose --profile prod up -d --build
```

پہلی دو کمانڈز Postgres، ایک S3 سے ہم آہنگ اسٹور، Word فائلوں کے لیے Gotenberg اور Mailpit شروع کرتی ہیں، اور بکٹ بناتی ہیں۔ آخری کمانڈ پروڈکشن امیج بنا کر چلاتی ہے۔

- OpenSign: http://localhost:8090
- Mailpit، ڈیولپمنٹ کے لیے مقامی ان باکس: http://localhost:8026

پروڈکشن امیج اصلی ای میل بھیجتی ہے، اس لیے اسے ایک اصلی ای میل اکاؤنٹ درکار ہے (مرحلہ 3)۔ اس کے بغیر OpenSign آزمانے کے لیے اسے ڈیولپمنٹ موڈ میں چلائیں، جہاں ہر ای میل Mailpit میں آتی ہے:

```sh
pnpm install
pnpm infra:up
cp .env.example .env
pnpm dev            # web app on http://localhost:5173
```

## 2. پہلا ایڈمن بنائیں

نیا انسٹال اپنے لاگ میں ایک **ترتیبی کوڈ** چھاپتا ہے، تاکہ آپ سے پہلے کوئی اور اسے اپنے نام نہ کر لے۔

```sh
docker compose logs app | grep "setup code"
```

ڈیولپمنٹ موڈ میں یہ اس ٹرمینل میں ہوتا ہے جہاں `pnpm dev` چل رہا ہے۔

OpenSign کھولیں اور ترتیبی کوڈ، اپنا نام، اپنی تنظیم، اپنی ای میل اور پاس ورڈ درج کریں۔ ہر مرحلہ کیا کرتا ہے، اس کے لیے [پہلی بار کی ترتیب اور ای میل](setup.md) دیکھیں۔

## 3. ای میل جوڑیں

OpenSign دعوت نامے، کوڈز اور دستخط شدہ دستاویزات ای میل سے بھیجتا ہے، اس لیے کسی کے بھیجنے سے پہلے وہ ای میل فراہم کنندہ مانگتا ہے۔ Resend API کلید اور ایسے ڈومین کا بھیجنے والا پتہ درج کریں جس کی آپ نے Resend میں تصدیق کی ہو۔ OpenSign آپ کو آزمائشی ای میل بھیجتا ہے اور صرف اسی وقت آگے بڑھتا ہے جب وہ کامیابی سے پہنچ جائے۔

ڈیولپمنٹ موڈ میں آپ کلید خالی چھوڑ سکتے ہیں: آزمائشی ای میل اور اس کے بعد سب کچھ Mailpit میں جاتا ہے۔

## 4. دستاویز بھیجیں

1. **دستاویزات** پر جائیں اور **نئی دستاویز** منتخب کریں۔
2. PDF یا Word فائل چھوڑیں، اسے عنوان دیں اور بنائیں۔
3. **فریقین** کے تحت اپنے آپ کو اپنی ای میل کے ساتھ دستخط کنندہ کے طور پر شامل کریں۔
4. فیلڈ ٹول بار میں فریق منتخب کریں اور صفحے پر **دستخط** فیلڈ رکھیں۔
5. **دستخط کے لیے بھیجیں** منتخب کریں۔

دعوت نامہ کھولیں، لنک پر جائیں، دستخط بنائیں یا ٹائپ کریں اور دستخط کریں۔ چند سیکنڈ بعد دستاویز **دستخط شدہ** ہو جاتی ہے، اور آپ دستاویز کے صفحے سے مہر شدہ PDF ڈاؤن لوڈ کر سکتے ہیں۔

## 5. نتیجہ جانچیں

سائیڈبار میں **دستاویز کی تصدیق کریں** کھولیں (یا `/verify` پر جائیں) اور مہر شدہ PDF چھوڑیں۔ OpenSign مہر اور ٹائم اسٹیمپ جانچتا ہے اور تصدیق کرتا ہے کہ اسی فائل پر اس نے مہر لگائی تھی۔ دستخط سمجھنے والا PDF ریڈر، جیسے Adobe Acrobat، بھی مہر دکھاتا ہے۔
