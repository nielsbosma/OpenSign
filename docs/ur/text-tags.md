# ٹیکسٹ ٹیگز، فارم امپورٹ اور فیلڈ کی شناخت

آپ کو ہر فیلڈ صفحے پر گھسیٹنے کی ضرورت نہیں۔ OpenSign فائل ہی سے فیلڈز تین طریقوں سے پڑھ سکتا ہے:

- **ٹیکسٹ ٹیگز** جو آپ Word فائل یا PDF میں لکھتے ہیں، جیسے `{{Tenant Sign;role=Tenant;type=signature}}`۔
- **PDF فارمز**: بھرنے کے قابل PDF کے فیلڈز OpenSign فیلڈز بن جاتے ہیں، ان قدروں کے ساتھ جن سے وہ بھرے گئے تھے۔
- ایڈیٹر میں **فیلڈز تلاش کریں** وہاں فیلڈز تجویز کرتا ہے جہاں صفحے پر بھرنے کے لیے لکیریں، انڈر اسکور یا خانے ہوں۔

ان میں سے کسی بھی طریقے سے بنے فیلڈز عام فیلڈز ہیں۔ آپ بھیجنے سے پہلے انہیں منتقل کر سکتے ہیں، ان کا سائز بدل سکتے ہیں، تبدیل کر سکتے ہیں یا ہٹا سکتے ہیں۔

## ٹیکسٹ ٹیگز

دستاویز کے متن میں جہاں فیلڈ چاہیے وہاں ٹیگ لکھیں۔ فائل اپ لوڈ کرنے پر OpenSign ہر ٹیگ کو اس کی جگہ پر فیلڈ بنا دیتا ہے اور ٹیگ کا متن صفحے سے نکال دیتا ہے، اس لیے دستخط کنندگان اسے کبھی نہیں دیکھتے۔ سطر کا باقی حصہ بالکل اپنی جگہ رہتا ہے۔

سنٹیکس DocuSeal جیسا ہے، اس لیے DocuSeal کے لیے بنے ٹیمپلیٹس بغیر تبدیلی کے چلتے ہیں:

```
{{Field Name;role=Tenant;type=signature;required=false}}
```

پہلا حصہ فیلڈ کا نام ہے، جو اس کے لیبل کے طور پر دکھایا جاتا ہے۔ اس کے بعد `key=value` اوصاف آتے ہیں جو سیمی کولن سے الگ ہوتے ہیں۔ ٹیگ نام چھوڑ کر کسی وصف سے بھی شروع ہو سکتا ہے، جیسے `{{type=checkbox}}`۔

| وصف | |
| --- | --- |
| `type` | فیلڈ کی قسم، نیچے دیکھیں۔ چھوڑنے پر `text`۔ |
| `role` | وہ فریق جو اسے بھرتا ہے، نام سے، جیسے `Tenant` یا `Landlord`۔ جو کردار دستاویز میں ابھی نہیں ہے وہ نئے فریق کے طور پر شامل ہو جاتا ہے؛ بھیجنے سے پہلے ان کی تفصیلات بھریں۔ کردار کے بغیر فیلڈ پہلے دستخط کرنے والے فریق کو جاتا ہے۔ |
| `required` | `false` فیلڈ کو اختیاری بنا دیتا ہے۔ فیلڈز ڈیفالٹ طور پر لازمی ہوتے ہیں، چیک باکس نہیں۔ |
| `readonly` | `true` فریق کو ڈیفالٹ قدر دکھاتا ہے مگر بدلنے نہیں دیتا۔ |
| `default` | وہ قدر جس سے فریق شروع کرتا ہے۔ |
| `title` | نام کے علاوہ کوئی لیبل۔ |
| `options` | `select` یا `multiple` فیلڈ کے انتخابات، کوما (یا `|`) سے الگ۔ |
| `option` | وہ ایک انتخاب جس کی نمائندگی `radio` بٹن کرتا ہے۔ ایک ہی نام کے ریڈیو ٹیگز ایک گروپ بناتے ہیں۔ |
| `format` | تاریخ کا فارمیٹ جیسے `DD/MM/YYYY` یا `MM/DD/YYYY`، یا نمبر کا فارمیٹ: `usd`، `eur`، `gbp`، `sek`، یا یہ کہ 1234 کیسا دکھے گا، جیسے `1 234,00 kr`۔ دیکھیں [نمبر اور تاریخ کے فارمیٹ](documents.md#number-and-date-formats)۔ |
| `min`، `max` | سب سے چھوٹا اور بڑا نمبر، یا سب سے پہلی اور آخری تاریخ بصورت YYYY-MM-DD۔ |
| `width`، `height` | فیلڈ کا سائز پوائنٹس میں (1/72 انچ)۔ ان کے بغیر فیلڈ ٹیگ جتنا چوڑا اور اس کے متن جتنا اونچا ہوتا ہے، اور دستخط، ابتدائی حروف اور تصاویر کو مناسب کم از کم سائز ملتا ہے جو لکیر سے اوپر کی طرف بڑھتا ہے۔ |

| قسم | فیلڈ |
| --- | --- |
| `text` | متن |
| `signature` | دستخط |
| `initials` | ابتدائی حروف |
| `date` | تاریخ منتخب کنندہ |
| `datenow` | دستخط کی تاریخ، خود بخود بھری جاتی ہے |
| `number` | نمبر |
| `select` | ڈراپ ڈاؤن |
| `multiple` | متعدد انتخاب |
| `radio` | ایک ریڈیو بٹن |
| `checkbox` | چیک باکس |
| `phone` | فون |
| `image`، `file` | تصویر یا فائل اپ لوڈ |
| `name`، `email`، `company` | فریق کی تفصیلات سے بھرے جاتے ہیں (صرف OpenSign میں) |

مثالیں:

```
{{Client Name;role=Client}}
{{Client Sign;type=signature;role=Client}}
{{Start Date;type=date;format=DD/MM/YYYY;role=Client}}
{{Region;type=select;options=North,South,East,West}}
{{Plan;type=radio;option=Basic}} Basic   {{Plan;type=radio;option=Plus}} Plus
{{type=checkbox;role=Client}} I accept the terms
{{Amount;type=number;format=sek;min=0}}
```

جو ٹیگ استعمال نہ ہو سکے وہ صفحے پر متن کے طور پر رہ جاتا ہے، اور اپ لوڈ کرتے وقت OpenSign وجہ بتاتا ہے: ایسی قسم جو OpenSign میں نہیں (جیسے DocuSeal کی `payment`، `stamp` یا `verification`)، بغیر قدر کا وصف، ایسی قدر جو فیلڈ قبول نہیں کرتا، یا دو سطروں میں ٹوٹا ہوا ٹیگ۔ جو اوصاف OpenSign کے کام کے نہیں، جیسے فونٹس اور رنگ، نظر انداز کر دیے جاتے ہیں۔

### Word میں ٹیگز لکھنا

ٹیگز کو عام متن کی طرح ٹائپ کریں۔ ہر ٹیگ ایک سطر میں رکھیں: اگر Word اسے توڑ دے تو نام چھوٹا کریں یا فونٹ چھوٹا کریں۔ ٹیگ کے فونٹ کا سائز فیلڈ کی اونچائی طے کرتا ہے، اس لیے 8 پوائنٹ متن کا ٹیگ چھوٹا فیلڈ بناتا ہے۔ ٹیکسٹ ٹیگز ان انسٹالز پر Word، OpenDocument اور RTF فائلوں میں کام کرتے ہیں جن میں دستاویز کنورٹر ہو، اور ہر اس PDF میں جس کا متن پڑھا جا سکے۔ اسکین شدہ صفحات میں متن نہیں ہوتا، اس لیے ان میں ٹیگز نہیں ہوتے۔

### ٹیگز بند کرنا

ٹیگز ہر اپ لوڈ پر پڑھے جاتے ہیں۔ ایسی فائل اپ لوڈ کرنے کے لیے جس کے متن میں اتفاقاً `{{` اور `}}` ہوں، API کے ذریعے `textTags=false` سے اسے بند کریں۔ [Scrive](scrive.md) اور [DocuSign](docusign.md) APIs ٹیگز کبھی نہیں پڑھتیں۔

## PDF فارمز

بھرنے کے قابل PDF فارم (AcroForm) اپ لوڈ کرنے پر فیلڈز بن جاتا ہے: ٹیکسٹ باکس متن کے فیلڈز، چیک باکس چیک باکسز، ریڈیو بٹن ریڈیو گروپ، فہرستیں ڈراپ ڈاؤن یا متعدد انتخاب، اور دستخط کے خانے دستخط کے فیلڈز۔ فارم میں بھری قدریں ڈیفالٹ قدریں بن جاتی ہیں، اور فارم میں لازمی نشان زد فیلڈز لازمی رہتے ہیں۔

جس فارم فیلڈ کا نام کسی فریق کے نام سے شروع ہو وہ اسی فریق کو جاتا ہے: `Tenant.Name` اور `Tenant name` Tenant کو جاتے ہیں۔ باقی پہلے دستخط کرنے والے فریق کو جاتے ہیں۔ ہر اپ لوڈ کی طرح فارم خود فائل سے ہٹا دیا جاتا ہے، اس لیے صرف OpenSign کے فیلڈز رہتے ہیں۔ XFA فارمز نہیں پڑھے جاتے۔

## فیلڈز تلاش کریں

فیلڈ ٹول بار میں **فیلڈز تلاش کریں** صفحات میں ایسی جگہیں دیکھتا ہے جہاں فیلڈ چاہیے:

- لکھنے کے لیے لکیریں اور انڈر اسکور کی قطاریں، جن کے ساتھ یا نیچے لیبل ہو،
- نشان لگانے کے لیے خالی خانے، جن کے ساتھ والا متن لیبل ہو۔

لیبل قسم طے کرتا ہے: Signature، Underskrift یا Firma دستخط کا فیلڈ بنتا ہے، Name یا Namnförtydligande نام، Date یا Datum دستخط کی تاریخ، Date of birth تاریخ منتخب کنندہ، Email، Phone اور Company اپنے فیلڈز، اور باقی سب متن۔

تجاویز ٹوٹی لکیر کی حد کے ساتھ بنتی ہیں اور آپ کے قبول کرنے تک کچھ محفوظ نہیں ہوتا۔ کسی ایک پر کلک کر کے اسے شامل کریں، یا **سب قبول کریں**۔ وہ ٹول بار میں منتخب فریق کو جاتی ہیں؛ دستخط اور ابتدائی حروف دستخط کنندہ کو جاتے ہیں۔ کسی تجویز پر ماؤس لے جائیں اور اسے مسترد کرنے کے لیے کراس پر کلک کریں۔ جن جگہوں پر پہلے سے فیلڈ ہو وہاں دوبارہ تجویز نہیں آتی۔

### AI کے ساتھ

جب [AI فراہم کنندہ](ai.md) ترتیب دیا گیا ہو اور **جائزوں کے لیے دستاویز کا متن بھیجنے کی اجازت دیں** آن ہو تو فیلڈز تلاش کریں **AI کے ساتھ بھی** کا اختیار دیتا ہے۔ تب OpenSign ماڈل کو ہر صفحے کا متن اس کے مقامات کے ساتھ، اور وہ جگہیں جو وہ پہلے ڈھونڈ چکا ہے، بھیجتا ہے، اور ماڈل کی تجاویز چمک کے نشان کے ساتھ شامل کرتا ہے۔ یہ کوئی تصویر نہیں بھیجتا، زیادہ سے زیادہ 30 صفحات اور تقریباً 40,000 حروف، اور کال AI بجٹ میں شمار ہوتی ہے۔ ہر AI شناخت [آڈٹ لاگ](audit-log.md) میں لکھی جاتی ہے۔

## API کے ذریعے

`POST /api/v1/documents/{id}/files` اور `documents.upload` ٹیکسٹ ٹیگز اور فارم فیلڈز پڑھتے ہیں جب تک `textTags` یا `formFields` کو `false` نہ کیا جائے۔ جواب کا `fields` بتاتا ہے کہ ہر ایک سے کتنے فیلڈز بنے، کون سے فریقین شامل ہوئے اور کون سے ٹیگز استعمال نہ ہو سکے۔

`documents.detect_fields` کچھ محفوظ کیے بغیر مسودے کے لیے تجاویز لوٹاتا ہے۔ AI ماڈل سے بھی پوچھنے کے لیے `ai: true` دیں۔ جو چاہیں انہیں `documents.set_fields` سے رکھیں۔ دیکھیں [API](api.md)۔
