# त्वरित शुरुआत

यह पृष्ठ आपको शून्य से अपनी ही मशीन पर हस्ताक्षरित दस्तावेज़ तक ले जाता है। प्रोडक्शन इंस्टॉलेशन के लिए आगे [डिप्लॉयमेंट](deployment.md) पढ़ें।

## 1. OpenSign को लोकल चलाएँ

आपको Docker और रिपॉज़िटरी की एक प्रति चाहिए।

```sh
git clone https://github.com/nielsbosma/OpenSign.git
cd OpenSign
docker compose up -d --wait postgres s3 mailpit converter
docker compose run --rm s3-init
docker compose --profile prod up -d --build
```

पहली दो कमांड Postgres, एक S3-संगत स्टोर, Word फ़ाइलों के लिए Gotenberg और Mailpit शुरू करती हैं, और बकेट बनाती हैं। आख़िरी कमांड प्रोडक्शन इमेज बनाकर शुरू करती है।

- OpenSign: http://localhost:8090
- Mailpit, डेवलपमेंट के लिए एक लोकल इनबॉक्स: http://localhost:8026

प्रोडक्शन इमेज असली ईमेल भेजती है, इसलिए उसे एक असली ईमेल खाता चाहिए (चरण 3)। इसके बिना OpenSign आज़माने के लिए उसे डेवलपमेंट मोड में चलाएँ, जहाँ हर ईमेल Mailpit में पहुँचता है:

```sh
pnpm install
pnpm infra:up
cp .env.example .env
pnpm dev            # web app on http://localhost:5173
```

## 2. पहला एडमिन बनाएँ

नए इंस्टॉलेशन के लॉग में एक **सेटअप कोड** छपता है, ताकि आपसे पहले कोई और इसे अपने नाम न कर ले।

```sh
docker compose logs app | grep "setup code"
```

डेवलपमेंट मोड में यह उस टर्मिनल में होता है जहाँ `pnpm dev` चल रहा है।

OpenSign खोलें, सेटअप कोड, अपना नाम, अपना संगठन, अपना ईमेल और एक पासवर्ड दर्ज करें। हर चरण क्या करता है, यह जानने के लिए [पहली बार का सेटअप और ईमेल](setup.md) देखें।

## 3. ईमेल जोड़ें

OpenSign आमंत्रण, कोड और हस्ताक्षरित दस्तावेज़ ईमेल से भेजता है, इसलिए किसी के भी भेजने से पहले वह ईमेल प्रदाता माँगता है। Resend API कुंजी और Resend में सत्यापित डोमेन का एक भेजने वाले का पता दर्ज करें। OpenSign आपको एक परीक्षण ईमेल भेजता है और तभी आगे बढ़ता है जब वह सफलतापूर्वक पहुँच जाए।

डेवलपमेंट मोड में आप कुंजी खाली छोड़ सकते हैं: परीक्षण ईमेल और उसके बाद का सब कुछ Mailpit में जाता है।

## 4. दस्तावेज़ भेजें

1. **दस्तावेज़** पर जाएँ और **नया दस्तावेज़** चुनें।
2. कोई PDF या Word फ़ाइल डालें, उसे शीर्षक दें और बना लें।
3. **पक्ष** के अंतर्गत खुद को अपने ईमेल पते के साथ हस्ताक्षरकर्ता के रूप में जोड़ें।
4. **फ़ील्ड** टैब में पक्ष चुनें और पृष्ठ पर एक **हस्ताक्षर** फ़ील्ड रखें।
5. **हस्ताक्षर के लिए भेजें** चुनें।

आमंत्रण खोलें, लिंक खोलें, हस्ताक्षर बनाएँ या टाइप करें और हस्ताक्षर करें। कुछ सेकंड बाद दस्तावेज़ **हस्ताक्षरित** हो जाता है, और आप दस्तावेज़ पृष्ठ से मुहरबंद PDF डाउनलोड कर सकते हैं।

## 5. नतीजा जाँचें

साइडबार में **दस्तावेज़ सत्यापित करें** खोलें (या `/verify` पर जाएँ) और मुहरबंद PDF डालें। OpenSign मुहर और टाइमस्टैम्प जाँचता है और पुष्टि करता है कि यही फ़ाइल उसने मुहरबंद की थी। हस्ताक्षर समझने वाला PDF रीडर, जैसे Adobe Acrobat, भी मुहर दिखाता है।
