# দ্রুত শুরু

এই পৃষ্ঠা আপনাকে শূন্য থেকে নিজের মেশিনে একটি স্বাক্ষরিত নথি পর্যন্ত নিয়ে যাবে। প্রোডাকশন ইনস্টলের জন্য এরপর [ডিপ্লয়মেন্ট](deployment.md) পড়ুন।

## 1. OpenSign লোকালি চালান

আপনার Docker এবং রিপোজিটরির একটি কপি লাগবে।

```sh
git clone https://github.com/nielsbosma/OpenSign.git
cd OpenSign
docker compose up -d --wait postgres s3 mailpit converter
docker compose run --rm s3-init
docker compose --profile prod up -d --build
```

প্রথম দুটি কমান্ড Postgres, একটি S3-সামঞ্জস্যপূর্ণ স্টোর, Word ফাইলের জন্য Gotenberg এবং Mailpit চালু করে ও বাকেটগুলো তৈরি করে। শেষ কমান্ডটি প্রোডাকশন ইমেজ বিল্ড করে চালু করে।

- OpenSign: http://localhost:8090
- Mailpit, ডেভেলপমেন্টের জন্য একটি লোকাল ইনবক্স: http://localhost:8026

প্রোডাকশন ইমেজ আসল ইমেল পাঠায়, তাই এর জন্য একটি আসল ইমেল অ্যাকাউন্ট লাগে (ধাপ 3)। এটি ছাড়া OpenSign চেষ্টা করতে চাইলে বরং ডেভেলপমেন্ট মোডে চালান, যেখানে প্রতিটি ইমেল Mailpit-এ জমা হয়:

```sh
pnpm install
pnpm infra:up
cp .env.example .env
pnpm dev            # web app on http://localhost:5173
```

## 2. প্রথম অ্যাডমিন তৈরি করুন

নতুন ইনস্টল তার লগে একটি **সেটআপ কোড** ছাপে, যাতে আপনার আগে অন্য কেউ এটি দখল করতে না পারে।

```sh
docker compose logs app | grep "setup code"
```

ডেভেলপমেন্ট মোডে এটি `pnpm dev` যে টার্মিনালে চলছে সেখানে থাকে।

OpenSign খুলুন, সেটআপ কোড, আপনার নাম, আপনার প্রতিষ্ঠান, আপনার ইমেল ও একটি পাসওয়ার্ড লিখুন। প্রতিটি ধাপ কী করে তা জানতে [প্রথমবারের সেটআপ ও ইমেল](setup.md) দেখুন।

## 3. ইমেল যুক্ত করুন

OpenSign আমন্ত্রণ, কোড ও স্বাক্ষরিত নথি ইমেলে পাঠায়, তাই কেউ পাঠানোর আগে এটি একটি ইমেল প্রদানকারী চায়। একটি Resend API কী এবং Resend-এ আপনার যাচাই করা ডোমেনের একটি প্রেরকের ঠিকানা লিখুন। OpenSign আপনাকে একটি পরীক্ষামূলক ইমেল পাঠায় এবং সেটি পৌঁছালে তবেই এগিয়ে যায়।

ডেভেলপমেন্ট মোডে আপনি কী খালি রাখতে পারেন: পরীক্ষামূলক ইমেল এবং এরপরের সবকিছু Mailpit-এ যায়।

## 4. একটি নথি পাঠান

1. **নথি** পৃষ্ঠায় যান এবং **নতুন নথি** বেছে নিন।
2. একটি PDF বা Word ফাইল ছাড়ুন, একটি শিরোনাম দিন এবং তৈরি করুন।
3. **পক্ষ**-এর অধীনে আপনার ইমেল ঠিকানা দিয়ে নিজেকে স্বাক্ষরকারী হিসেবে যোগ করুন।
4. ফিল্ড টুলবারে পক্ষটি বেছে নিন এবং পৃষ্ঠায় একটি **স্বাক্ষর** ফিল্ড বসান।
5. **স্বাক্ষরের জন্য পাঠান** বেছে নিন।

আমন্ত্রণটি খুলুন, লিংক অনুসরণ করুন, একটি স্বাক্ষর আঁকুন বা টাইপ করুন এবং স্বাক্ষর করুন। কয়েক সেকেন্ড পরে নথিটি **স্বাক্ষরিত** হয়ে যায়, আর আপনি নথির পৃষ্ঠা থেকে সিলমোহরকৃত PDF ডাউনলোড করতে পারেন।

## 5. ফলাফল যাচাই করুন

সাইডবারে **একটি নথি যাচাই করুন** খুলুন (বা `/verify`-এ যান) এবং সিলমোহরকৃত PDF ছাড়ুন। OpenSign সিল ও টাইম স্ট্যাম্প যাচাই করে এবং নিশ্চিত করে যে ঠিক এই ফাইলটিতেই সে সিল দিয়েছিল। স্বাক্ষর বোঝে এমন কোনো PDF রিডার, যেমন Adobe Acrobat, সিলটিও দেখায়।
